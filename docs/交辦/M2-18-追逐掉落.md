# M2-18 追逐掉落（交辦）

照 M2-17 定稿規格（數值設計師 v1.0）實作。以下「交辦摘要」是製作人交辦時的文字，「規格原文」是數值設計師 Page「給開發工程師（M2-18）」節的原文，照貼不改。

## 交辦摘要

- 常數放 js/craft.js、NEW_P 旁：CHASE = { b: 0.014, e: 0.0014, cap: 500, ptB: 5, ptE: 1, lv: 45, ec: 4 }；FEEL_TG = 1500。
- 平機率（Math.random），不走 prdRoll。
- 輪末王（m.boss && !m.mini）每隻 +5 點並判 1.4%；點數 ≥500 的輪末王必掉。菁英判 0.14%，沒中 +1 點，菁英不觸發必掉。任何一件追逐物品掉了，點數歸零。
- 每輪只有時間上前 4 隻（CHASE.ec）菁英參與判定。
- 地點怪物等級 ≥45 才開放（第 15 個主幹地點 Lv48 起），開放前不判定也不累計；照 TIER_P.gLv 的現有寫法判斷。
- 重複保護。掉落池：主幹是 4 王印；賽制線是該線的 2 個基底，該線菁英也照 0.14% 判定。
- 存檔 S.chase = { pts: 0, got: {} }，舊存檔沒有就補上。
- 有感保底：K = max(3, floor(FEEL_TG ÷ 最近 10 輪平均秒數))。連續 K 隻輪末王都沒有有感掉落時，輪流給 1 件：珠寶→破裂石→追憶之墨，跳過還沒開的；給了就把計數歸零。
- 鍛造台 13–16（只開破裂石）時，有感保底不給破裂石，改給材料包＝該地點 5 分鐘的自然材料掉落量（依最近 10 輪平均），計為有感掉落。
- 掛機卡加一行「下一件保底 n%」，n = floor(pts / 5)，加一條細條。390×844 只占一行、不換行，不加說明文字；1280×720 同一行。
- 追逐物品掉落：全寬橫幅＋稀有度外框，跟通貨／珠寶光柱分開（正式演出素材是 M2-19，美術另做，這裡先用簡單版）。
- 離線摘要「離開的時候」多一列：「追逐物品 ×n、目前保底 n%」，一列彙總，不要一件一行。

虛擬碼裡的名稱（SEALS、LINE_BASES、pick、S.prd.feel、mobLv、killMat、dropCur）是示意，對應到 repo 現有的程式。4 王印、賽制線基底、追憶之墨等物品在程式裡不存在、或規格跟程式對不上的，用最小的方式接上，列成「待數值設計師確認」。

驗收：

1. 擴充 tools/loot_check（或新增工具）跑 100 小時模擬，每小時 25 輪、1★，≥200 個種子，結果表對照：
   - 每小時 0.50–0.62 件；平均間隔 1.60–1.95 時；保底觸發率 24–33%；單一種子 100 小時 46–67 件（P1–P99）
   - 點數 ≥500 的輪末王沒掉：0 次；兩件之間累積點數 ≤510；最長空窗 ≤3.5 時；離線 12 小時 ≥3 件
   - A8：有感掉落空窗 P95 ≤30 分、每人最長 ≤45 分
   - 速度下限：5★、每小時 60 輪平均間隔 ≥0.5 時
   - 鍛造台 13–16：有感保底給的破裂石 0 件，材料包有出現且計入有感掉落
   不准為了過關放寬檢查或改區間；不過就照實寫出來。
2. `node tools/check.js` 全過，craftDo 結果不變；新邏輯（開放門檻、必掉、歸零、重複保護、舊存檔補欄位、前 4 隻菁英）加進 check.js 測試。
3. touch_check 六種尺寸 0 失敗。
4. 390×844 和 1280×720 截圖：掛機卡保底那行不換行，追逐橫幅和離線摘要不遮擋其他 UI。存到 docs/production/evidence/M2-18/。

const CHASE = { b: 0.014, e: 0.0014, cap: 500, ptB: 5, ptE: 1, lv: 45, ec: 4 };
const FEEL_TG = 1500; // 有感保底：K = max(3, floor(FEEL_TG / 最近 10 輪平均秒數))
// 每輪只有前 CHASE.ec 隻菁英呼叫 chaseRoll(1, ...)
// 存檔：S.chase = { pts: 0, got: {} }；舊存檔沒有就補 { pts: 0, got: {} }

// killMat / dropCur 內，kind 1 = 菁英、kind 2 = 王；isRoundBoss = m.boss && !m.mini
function chaseRoll(kind, node, isRoundBoss) {
  if (mobLv(node.t) < CHASE.lv) return null;          // 開放前不判定也不累計
  const C = (S.chase = S.chase || { pts: 0, got: {} });
  if (kind === 1) {
    if (Math.random() < CHASE.e) return chaseGive(node);
    C.pts += CHASE.ptE; return null;                    // 菁英不觸發必掉
  }
  if (kind === 2 && isRoundBoss) {
    C.pts += CHASE.ptB;
    if (C.pts >= CHASE.cap || Math.random() < CHASE.b) return chaseGive(node);
  }
  return null;
}
function chaseGive(node) {
  const pool = node.line ? LINE_BASES[node.line] : SEALS;   // 主幹 4 王印；賽制線 2 基底
  const fresh = pool.filter(k => !S.chase.got[k]);
  const k = pick(fresh.length ? fresh : pool);
  S.chase.got[k] = 1; S.chase.pts = 0;
  return k;
}
// 掛機卡：下一件保底 n% ，n = floor(S.chase.pts / 5)

// 有感保底：S.prd.feel = 連續幾隻輪末王沒有任何有感掉落
// feel >= K 且這隻王沒有有感掉落 → 輪流給 1 件（珠寶→破裂石→追憶之墨，跳過沒開的），feel = 0
