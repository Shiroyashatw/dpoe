# 營地、打造與解鎖表（0.5：PoE 式增量遊戲）

2026-11-15 定案（討論清單第 10、11 項）。這份是 0.5 的權威：跟企劃書 2.2、第 4 節、第 5 節衝突時以這裡為準，企劃書那幾節只改定位句並指到這裡。**0.5.0（12-1）做完**：鍛造台那張表、材料、打造、分解、戰鬥不掉裝、營地的骨架；另外三座 12-2。待做清單「0.5」區塊照這裡排。調查依據 `docs/增量遊戲參考.md`（20 款）。數字全部 ⚠️ 暫定，要用新存檔逐分鐘對。

## 0. 一句話與原則

**一句話**：你設計一套 build 讓它自己去打，打回來的材料在營地打造裝備、蓋設施，設施再解鎖更深的做裝。

**為什麼改**（使用者，2026-11-15）：0.4.10 之後自己玩與 Opus 試玩都是「只有戰鬥爽、其他不足、掉寶無感」。深度多深都是假的——有些人一開始就玩不下去。Melvor 戰鬥簡陋卻成功，因為一步一步給。而且**掛機掉 N 件裝跟自己手刷掉 N 件的體感不一樣**：掛機的掉落是背景噪音，開獎要放在玩家自己按下去的那一下——打造。

**原則**
1. **確定性放在進度，隨機只留在開獎**（設計原則第 4 節）。進度＝營地設施的等級與節點推進，花多少、還要幾分鐘一開始就算得出來；隨機＝打造出哪些詞幾階、掉哪顆通貨、珠寶哪個大點。
2. **戰鬥不掉裝備。** 戰鬥掉靈魂、金、材料、通貨、精髓、珠寶、追憶之墨。裝備全部在鍛造台用材料打造出來（調查：蘑菇勇者、Shop Titans 都這樣做，開獎從戰鬥搬到打造的按鈕；沒有一款是確定性製作）。
3. **上限由工藝決定、工藝由時間與推進解鎖**：節點推進給材料的階（決定打造出來的物品等級），鍛造台等級給配方、機率與批量。破裂 ★ 由破裂石與完美石做出來，不再是運氣。
4. **垃圾就是燃料**：打造出來不要的立刻分解成材料與靈魂；自動分解是早期解鎖，倉庫不會被塞滿。
5. **做減法但不刪內容**：82 招、77 顆輔助、15 個昇華、3917 個天賦點、五條賽制全部留著，**藏起來**（不灰顯），設施升到那一級才出現。新手開局看到的只有：一把劍、一招、鍛造台的「打造」、第一個地點。
6. **營地是解鎖表的畫面，不是第二套經濟**（調查：Melvor 的 Township 要維護、要修理是負分）：設施只吃戰鬥帶回來的同一批資源，蓋好就一直在，沒有損壞、沒有計時器、沒有人口。

## 3. 營地：四座設施、四張短表

**畫面**：藏身處那張圖改成營地（第一版先不重畫，四座設施各一個分頁；手機底部分頁「做裝」改成「營地」）。每座設施一張表：目前等級、下一級要什麼、「照現在的速度還要 N 分鐘」、這一級解鎖什麼；**只顯示下一級**，再下面寫「還有 N 級」。升級鈕只在夠的時候亮；不夠寫「還差 N・照現在的速度 M 分鐘」（靈魂／時照本次掛機算）。**鍛造台是主設施**：其他三座的等級不能超過鍛造台（調查：玩家最在乎決定上限的那一座——神燈、熔爐、筒倉）。

## 4. 戰鬥掉什麼

**不掉裝備。** 每隻怪掉靈魂與金照舊，另外：

| 掉什麼 | 來源 | 用途 |
| --- | --- | --- |
| **材料三種**：鐵、皮、靈絲 | 小怪 30% 掉 1、菁英 3、王 8（0.5.0 實測後定的，×星級；原本 1～2／5／15 太多）；鐵一開始就掉，皮、靈絲在鍛造台 Lv3、Lv8 之後才掉，開了的種類隨機一種；**有階 T1～T6 跟著節點等級**（`craft.js` 的 `matTier`：`tierIlvl` 三個一階，Lv5 的點 T1、Lv18 T2、Lv83 T6）；自動吸收、不落地 | 打造（物品等級＝3T−2：T1 → 1、T6 → 16）、設施升級 |
| 通貨 | 照鍛造台等級開關，任何節點都掉；賽制解鎖後它的節點掉得多 | 做裝 |
| 精髓 | 鍛造台 Lv5 起小怪低機率、菁英照星級、王保底 1 | 做裝 |
| 珠寶 | 鍛造台 Lv17 起任何節點低機率；2 個大點的留給涿鹿兵主 | 天賦樹（隨機性最強的掉落，是「心跳」） |
| **追憶之墨** | 鍛造台 Lv17 起王低機率（偽隨機保底）；陰兵借道的將領保底 | 打造時加一瓶保證一條追憶詞（追憶池照舊只收改規則的詞） |

- 材料對應基底系：鐵＝護甲系防具與所有武器；皮＝閃避系、箭袋；靈絲＝能量護盾系與法器；混合系吃兩種各一半；飾品（戒指、項鍊、腰帶）吃鐵加金；護符照舊小機率直接掉（它不是裝備）。0.5.0 不列 309 個基底的表，`craft.js` 的 `baseMat(b)` 照基底的 `k` 與防禦類型算（`check.js` 驗每個基底都有材料）。
- 崇高石掉率壓低（Opus：第 2 分鐘就掉、整場 12 顆）：鍛造台 Lv7 才開始、王保底 1 照舊、菁英 8% → 3%（⚠️）。通貨是戰鬥唯一的「開獎型」獎勵，演出（光柱、橫幅、落地音、掉落紀錄）照舊、對象換成通貨、珠寶、追憶之墨。
- 裝備的掉落演出、地上標籤、★ 自然掉落（`makeFrac`、`S.prd.frac`）、過濾器、撿起率統計全部拿掉。

## 5. 打造（鍛造台的主畫面）

**是什麼**：選部位 → 選系（開了才有）→ 選數量（上限看鍛造台等級）→ 按「打造」，扣材料，一件一件翻出來（沿用 0.4.1 的翻牌 `revealOpen`），每一件立刻跟身上比（現有的 `cmpHTML`、▲），一個決定：**換上／留／分解**；批量時照自動分解規則處理，只翻出留下來的。

**規則**
- 物品等級＝用的材料的階（T1 材料打出 Lv5 水準的裝、T6 打出 Lv83 水準）；基底照部位與系在那個階裡固定一個（不隨機）。所以**推進才有高階裝，鍛造台給的是機率與批量**。
- 稀有度照鍛造台等級（⚠️）：Lv0 白 70%／藍 30%；Lv4 起有黃 10%；Lv10 白 30／藍 50／黃 20；Lv16 白 10／藍 50／黃 40。偽隨機保底：連續 n 件沒黃下一件必黃（`prdRoll`）。
- 詞綴照掉落的規則骰（`mkItem`／`rollAff`，最高 T1）；品質、孔照掉落的規則骰（品質 20% 以上只能打造出來，不能再補）。
- 費用：一件＝部位大小 × 那一階的材料數（武器 8、胸甲 8、頭、手、鞋、腰、盾、法器、箭袋 5、戒指與項鍊 3；飾品另外金 10 × 階；`craft.js` 的 `craftCost`）。**不花時間、不用計時器**（調查 3.5：計時器只是「等」）。
- 追憶之墨：有就能勾「加一瓶」，這一件保證一條追憶詞。
- **分解**：回收材料 50%（倉房 Lv2 65%、Lv5 80%）＋靈魂（物品等級 × 2）＋金（舊的賣價），黃裝另外回 1 顆蛻變或增幅（`craft.js` 的 `salvageDo`；倉庫的「賣」全部改成分解）。自動分解規則 `S.auto2` 在鍛造台 Lv8（留稀有度 ≥ r）、Lv14（另外留最好的詞 T ≤ t、有追憶、▲）。
- 商人賭裝（`GAMBLE`／`gambleDo`）併進打造：它本來就是「付錢照等級產一件隨機詞的裝備」，第一版就是把金幣換成材料、物品等級換成材料的階、加數量。天星商會改成倉房的「商會」分頁。
- 倉庫：只放打造後留下來的（容量 300，滿了打造出來的直接分解）；篩選只剩大類、部位與排序，膠囊、搜尋拿掉（過濾器面板 0.5.0 只是從選單與設定拿掉入口，程式留到 12-3 一起刪）。

## 6. 做裝：一條路加兩顆石

填 → 淬鍊 → **破裂石** → 填滿 → **完美石** → 聖化 → 腐化。填、淬鍊、聖化、腐化、精髓、轉化石、預知石、預兆照企劃書 5.3。

| 石 | 條件 | 效果 | 來源 |
| --- | --- | --- | --- |
| **破裂石** | 黃裝、四條以上詞、還沒有破裂詞 | 隨機一條變成破裂 ★：升到 T0、鎖住（轉化石、淬鍊、聖化都不碰它）；一件只能一條 | 鍛造台 Lv13 起掉（菁英低機率、王小機率，偽隨機保底）；每 1～2 小時一顆的大事 ⚠️ |
| **完美石** | 黃裝、六條全滿 | 隨機一條**沒破裂的**詞升到 T0（不鎖、不算破裂）；一件只能用一次 | 鍛造台 Lv19 起掉，比破裂石稀有一級 ⚠️ |

- 兩顆都只加不減、不會失敗、不動別的詞。一件最多兩個 T0（一個 ★ 一個完美），這是終局目標裝（使用者 2026-11-15 確認「不算破裂、可疊」）。
- 淬鍊對 T0 詞照舊只在 T0 範圍內重骰。腐化的爆開照舊。
- 企劃書 5.4「只有掉落才有的四樣」整個作廢：T 與品質由材料的階與鍛造台決定、★ 由石頭做、追憶由墨保證。
