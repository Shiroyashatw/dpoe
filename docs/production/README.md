## 方向與核心循環

dungeonPOE（dpoe）是 PoE 式增量／掛機遊戲：玩家配一套 build 讓 AI 自己刷地點（一輪＝4 波＋王，戰鬥不掉裝），營地產生器產材料，鍛造台打造裝備、換上或分解，升解鎖表設施開更難的地點、星級、技能格與更深的做裝。打造是骨幹，再加一層只從王與菁英掉、有保底的追逐物品（王印、異寶基底）。主打「PoE 的做裝深度，掛機也不會乾旱」，包裝是台灣民俗暗黑題材（山海經、酆都、陰兵借道）。同一份程式：網頁／PWA 免費導流、Steam 買斷（Steam 階段延後，上癮度達標後再評估）。原生 JS＋Canvas，GitHub Pages 部署。

## 平台規則

- M2 起直立 390×844 與桌機 1280×720 同級，兩個都驗過才算完成；再驗 375×667、橫向、1440×900。桌機以滑鼠＋鍵盤為主，也要能只用滑鼠玩。
- M4S（Steam）：桌機 1280×720 與 Steam Deck 1280×800。製作人、數值設計師、mumi 的任務不掛尺寸。
