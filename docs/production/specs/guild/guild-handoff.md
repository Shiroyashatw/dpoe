工程要點：

- `tradeDo` 擴充成 `tradeDo(kind, n)`；「換到上限」一次算完 n，**先判斷是否有材料會歸 0**，是才開確認卡；確認後一次結算（不要迴圈呼叫 n 次觸發 n 次重畫與 n 條結果行）。
- 額度：連續回復、最多存 1 小時份、從 0 起、離線照算（材料來源 §6）。額度 0 時不扣材料、不給通貨、按鈕停用；不再跳戰場浮動字。
- 面板開著時戰鬥照刷；額度每秒更新文字與條，按鈕的 n 同步更新，不重建整個面板（避免焦點跳走）。
- 倉房展開卡原本的商會 chip 區改成一顆「商會」入口鈕。
