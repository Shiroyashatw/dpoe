## 2. 暫稱、新字串與符號（給本地化編輯）

### 2.1 暫稱（名詞表沒有或定義不同）
- **精髓粉**（通貨格名）；9 類粉名：生命粉、防禦粉、元素粉、物理粉、暴擊粉、速度粉、法術粉、抗性粉、能力值粉。名詞表若有「精髓」要同步改。
- 粉的三檔：「定類」「下限提高」「次頂階以上」。
- **煉製**、**保留配方**、**鼎孔**、空孔、清空鼎、單用粉。
- **已鎖**（揭曉卡自動鎖的標）、留著、跳過動畫、其餘分解、全部收下、全部翻開、只看稀有以上。
- **加詞石**、**至臻石**（新通貨名）。拿掉蛻變石／增幅石／富豪石；名詞表若有「高階／完美通貨」要拿掉。
- 「鼎」：名詞表定義是放預兆；定案改成裝粉，要改定義。
- 轉化石跟 main 混沌石共用圖，名字不共用。

### 2.2 改名待辦
- 「完美石」「完美災魘石」保留原名；跟至臻石、「完美通貨」用字相近，改名記為待辦。

### 2.3 符號
- **✦＝頂階詞**（圖示格右上 ✦n、詞列前 ✦）。讀屏照 item-display：「最好的階 {n}」。
- **破裂＝`affix_frac` 圖示＋「破裂」字標**，物品上不用 ★。
- **★ 只剩地圖星級**（頂列「★2 怪物 Lv 38」）。舊 `hud.js` 詞列尾「T{n} ★」＝破裂的寫法作廢。
- ▲（`--good`）／▼（`--red`）＝跟身上同部位比。
- ⚠️ item-display §2：「畫面上不寫『頂階』兩個字」。鍛造預覽目前有「頂階 1/6」「頂階機率」「不保證頂階」（06、07）。建議改成 ✦ 圖示寫法（例：「✦ 機率 1/6」「不保證 ✦」）。請本地化編輯定稿用字，畫面跟著改。
- 卡面不寫「大獎」；卡上不顯示百分比分數。

### 2.4 新字串（節錄；完整見三個畫面表的備註欄）
- 「重擲全部非破裂詞」（07b 預覽第一行、主鈕副行、右上）
- 「{粉}不夠（還差 {n}）」、「照庫存還能洗 {n} 次」、「煉製後同一組留在鼎裡」
- 「T1／T2 各半（頂階 1/2）」＋另一行「不保證頂階」；全頁不寫「必定」「保底」
- 「其餘分解（含稀有，長按確認）」、「其餘分解：跳過『留著』與已鎖的卡；沒翻的先翻開再分解（不分解沒看過的）。」
- 「已鎖：要分解先點『已鎖』解開」、「點一下翻開」、「亮邊：稀有以上」
- 「連刷第 2 次起可開；✦2 以上照樣金框、自動鎖」
- 「腐化？」「全部鎖定，之後不能再改。15% 會爆開，這件裝備就沒了。」「長按腐化」
- 淬鍊：「這件已淬鍊 {n} 次」、「淬鍊完成：{詞} {舊}% → {新}%」

## 4. 工程注意事項

- 本檔是畫面規格；機制改動（三顆通貨、粉、鼎裝粉、加詞石回收）要改 `craft.js`／`forge.js`／`data.js`，另開任務，不在這個文件 PR。
- ✦n 直接用 `charpanel.js` 的 `CH_STAR` 與 `.cs` 樣式；頂階判定 `a.T <= itemT`；✦2 以上自動鎖對齊 `items.js` midMark。
- 破裂詞：格子左下 `affix_frac` 16；詞列有任一破裂詞時每列留 16px 破裂欄。不要再輸出「T{n} ★」。
- 揭曉卡 216×216（同物品提示）；20 件 2×10 小卡 104×104 間距 8；不輸出任何分數。
- 長按共用 `holdAsk`（`HOLD_MS = 600`）；揭曉「其餘分解」含稀有以上才長按。
- 頓幀／輕震要接設定裡的暈動開關。
- 鍵位：主檔 §8 標 ⚠️ 的要新接，接進 stash12 手把標準配置。
- 主檔 §9 的 main 差異都以規格為準。
- 驗收：照 [REVIEW-CHECKLIST.md](../../evidence/forge/REVIEW-CHECKLIST.md) 開雲端驗證工作階段。
