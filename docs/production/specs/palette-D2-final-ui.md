**形狀規則（擋關項）**
1. `--act` 只用在**填色的圓角矩形按鈕**（圓角 6、高 ≥40、熱區 ≥44、2 px `--act-edge`、字 `--on-act`）。不能拿來當字色、線、光暈、光柱、圖示或物品框。
2. 傳奇 `#fa8915` 只用在字、◈、光柱和物品框，**永遠不當按鈕底**；傳奇字也不放在 `--act` 上（2.66，不夠）。
3. 一個畫面同時最多 **1 顆** `--act`。戰場是「去營地」；營地單座卡是「▲ 升級」；確認框是確認鈕；天賦樹是「確認配點」。其他按鈕一律用 `--btn2`。分頁徽章、營地格子印章原本用 `--act`（`M2-36-demo-tokens.md`（已刪） 第 71 行：`.tab .bdg`、`.plq .stp.can`、`.cc .stamp.can`），一律改成 `--btn2` 底加 `--ready` 左標。
4. 主鈕放在 `--panel`、`--plate-world` 或磚縫上（框 ≥4.4）。不准直接放在淺磚上（框對淺磚只有 2.26）；HUD 上的主鈕一律墊 `--plate-world`。
5. 量法（v1.1 改，只量 UI 層）：主鈕以外的 UI 元件 0 個用 `--act` 系列填色；UI 層裡琥珀色相像素（h 50°–90°、C* >20、L* 30–50）只准來自傳奇字反鋸齒和金幣圖示。場景（怪物、地形、掉落、光柱）不計，但主鈕外 40 px 內對 `#7c5729` ΔE2000 <15 的像素 ≤50（示意實量 3／0／0／0／0）。
