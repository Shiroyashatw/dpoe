## 2. 紅水、藍水看不到（mumi 第 2 項）

**問題**：D1 截圖（H01、H19_flask，兩尺寸）HUD 上沒有獨立的藥劑鈕；藥劑只在技能鈕狀態（H19）出現，桌機只有 1／2 鍵（K05）。玩家找不到。

**程式事實**（數值設計師查 game.js:956–970、hud.js:263–266）：紅水、藍水**不限次數**，各自冷卻 3 秒，**不用充能**。製作人已確認照這個制度做。

**裁定**
- 生命藥劑、魔力藥劑變成常駐 HUD 鈕，各一顆：直立 56×56 pt（拇指區，技能鈕左邊），桌機 48×48 px（生命／魔力條右端下方，技能鈕右邊）。
- 鈕內：藥劑圖示 32（整數倍）；底填 `--hp` #823630／`--mp` #304e8b。**不畫次數、不畫「n／3」**。
- **只畫冷卻**：按下後 3 秒，外圈 3 px 冷卻環＋鈕面扇形掃過（順時針，剩餘部分蓋 `rgb(var(--scrim-rgb) / 0.5)`），圖示降到 50% 亮度；冷卻完環消失、圖示回全亮。環與掃過的邊用 `--hp-hi` #ae766c／`--mp-hi` #7d81ac（美術總監 13:31 寫進 M2-36；對 `--panel` 3.45／3.43:1，≥3:1；畫面未驗）。`--hp`、`--mp` 對 `--panel` 只有約 1.55，不能拿來畫環。
- 冷卻中按：不喝、不出字；鈕做「忙碌」小抖（水平 2 px，≤80 ms）；減少動態不抖，改 2 px `--border-hi` 外框 120 ms。沒有停用狀態（不會用完）。
- 桌機左上角鍵帽「1」「2」（mumi 15:56 S4 a；M2-33-1 §11）；觸控不畫鍵帽；手把鍵位排 M4S。
- 低血（生命 <35%，跟低血紅邊同門檻）且生命藥劑**不在冷卻**：外框 2 px `--hp-hi` 1 Hz 呼吸（不透明度 0.4↔1，ease-in-out，不閃爍）；冷卻中不呼吸。減少動態：常亮 2 px 外框，不動。
- 開面板／抽屜時照樣能按 1／2（K05）。

## 4. K／M 縮寫：哪裡縮、哪裡寫完整（mumi 第 4 項）

**規則本身**歸數值設計師，見 `specs/number-abbrev.md` v1.1（名詞表 v0.6.15）。一句話：<10,000 寫完整加千分位；≥10,000 縮成 3 位有效數字 K／M／B／T（10.0K、12.3K、123K、1.23M），之後 1.23e15；中文也用 K／M／B／T，不用萬、億；擁有／獲得捨去、費用／需求進位；買得起的顏色與實心鈕一律用精確值；百分比、時間不歸這條。

**位置（UIUX 定）**
| 縮寫 | 寫完整數字（加千分位） |
| --- | --- |

| 掛機卡（標題列、清單 ×n、「離開 4 分・靈魂 +n」那行） | 裝備比較 |

| 戰鬥飄字（傷害、＋金） | 通貨明細（§9） |
| 營地升級格與單座卡的費用、「差 {n}」 | 屬性頁（角色 DPS、生命、護甲） |
| 追逐物品面板的進度數 | 設定頁 |
| 鍛造的材料數量格（tile） | 離線結算（一次性的收穫，全屏放得下） |

- 縮寫的數字：觸控點一下、滑鼠移上去 300 ms，出小說明框寫完整值（14／16，M2-33-1 §9）；放開／移開就收。說明框不擋下一個輸入。
