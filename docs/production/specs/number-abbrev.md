## 規則
1. 小於 10,000：寫完整數字，加千分位逗號（9,999）。
2. 10,000 以上：縮寫成 3 位有效數字，單位 K（千）、M（百萬）、B（十億）、T（兆）：12.3K、123K、1.23M、1.23B、1.23T。
3. 超過 T（≥ 1e15）：寫 1.23e15。
4. 中文介面也用 K／M／B／T，不用「萬」「億」。英文介面同一套格式。
5. 不刪尾數 0（12.0K、1.00M），寬度固定。最寬 5 個字元（9,999、12.3K、1.23M）；只有 e 記法例外（1.23e15 是 7 字元）。
6. 取整方向：
   - 擁有、庫存、獲得、掉落的量：無條件捨去（floor）。
   - 費用、需求：無條件進位（ceil）；進位到 1000 時換下一個單位（999,999 → 1.00M）。
   - 結果：差一點點就不夠時，畫面上永遠看得出不夠（例 9,999 擁有／10,000 費用 → 「9,999／10.0K」；10,050 擁有／10,099 費用 → 「10.0K／10.1K」）。
   - 買得起的顏色、實心按鈕一律用精確值判斷，不看顯示的字。
7. 百分比、時間不歸這條規則管（時間照名詞表 `1h 05m` 格式）。

## 演算法
```
abbr(n, mode)   // mode: 'own' 捨去、'cost' 進位
  if n < 10000: return 千分位(mode === 'cost' ? ceil(n) : floor(n))
  units = [K 1e3, M 1e6, B 1e9, T 1e12]
  取最大的 u 使 n / u >= 1；若 n >= 1e15 改用 e 記法
  x = n / u；d = x < 10 ? 2 : x < 100 ? 1 : 0          // 小數位
  y = (mode === 'cost' ? ceil : floor)(x × 10^d) / 10^d
  若 y >= 1000：換下一個單位重算（只有 cost 會發生）
  return y.toFixed(d) + 單位                          // toFixed 保留尾數 0
```
浮點注意：先用整數運算或加一個極小值修正（例 x × 10^d 先 round 到 1e-9），避免 12.3 × 10 = 122.99999 被捨去成 12.2K。
