## 結論
- 平機率（不走 prdRoll）：王 1.4%、菁英 0.14%，加保底 500 點。基準（每小時 25 輪、1★）平均 1.76 小時一件、P99 3.18、最長約 3.3 小時，保底觸發率 28.6%。
- A9 過：點數 ≥500 的輪末王一定掉。
- A8 過：有感保底 TG 1500 下 12 格全過，P95 14.4～26.6 分、每人最長最大 29.8 分。
- 速度下限過：EC 4 讓 5★、1 分鐘一輪的平均間隔 0.567 小時（≥ 0.5）。

## 給開發工程師
```js
// 常數（craft.js，放在 NEW_P 旁）
const CHASE = { b: 0.014, e: 0.0014, cap: 500, ptB: 5, ptE: 1, lv: 45, ec: 4 };
const FEEL_TG = 1500; // 有感保底：K = max(3, floor(FEEL_TG / 最近 10 輪平均秒數))
// 每輪只有前 CHASE.ec 隻菁英呼叫 chaseRoll(1, ...)
// 存檔：S.chase = { pts: 0, got: {} }；舊存檔沒有就補 { pts: 0, got: {} }

// killMat / dropCur 內，kind 1 = 菁英、kind 2 = 王；isRoundBoss = m.boss && !m.mini
function chaseRoll(kind, node, isRoundBoss) {
  if (mobLv(node.t) < CHASE.lv) return null;          // 開放前不判定也不累計
  const C = (S.chase = S.chase || { pts: 0, got: {} });
  if (kind === 1) {
    if (Math.random() < CHASE.e) return chaseGive(node);
    C.pts += CHASE.ptE; return null;                    // 菁英不觸發必掉
  }
  if (kind === 2 && isRoundBoss) {
    C.pts += CHASE.ptB;
    if (C.pts >= CHASE.cap || Math.random() < CHASE.b) return chaseGive(node);
  }
  return null;
}
function chaseGive(node) {
  const pool = node.line ? LINE_BASES[node.line] : SEALS;   // 主幹 4 王印；賽制線 M2 關閉
  const fresh = pool.filter(k => !S.chase.got[k]);
  const k = pick(fresh.length ? fresh : pool);
  S.chase.got[k] = 1; S.chase.pts = 0;
  return k;
}
// 掛機卡：下一件保底 n%，n = min(100, floor(S.chase.pts / 5))（點數最多到 506–510，顯示夾在 100）
// 靈魂包：掉落紀錄自成一類 pack，不算進掛機卡的通貨數；內部計為有感掉落（歸零 feel）

// 有感保底：S.prd.feel = 距離上一次任何有感掉落，經過幾隻輪末王；任何怪物（一般怪、菁英、輪末王）掉出有感掉落都歸零，只有輪末王沒掉時 +1
// feel >= K 且這隻王沒有有感掉落 → 輪流給 1 件（珠寶→破裂石→追憶之墨，跳過沒開的），feel = 0
// 鍛造台 13–16（只開破裂石）：不給破裂石，改給靈魂包，計為有感掉落
// feel 上限 K；珠寶收藏滿 30 顆時保底珠寶換 500 靈魂，仍計有感；m.mini 當菁英
```

## 畫面資訊量（390×844／1280×720）
- 掛機卡：多一行「下一件保底 n%」加一條細條；390×844 只占一行，不加說明文字；1280×720 同一行。位置由 M2-19 定。
- 掉落演出：平均每 1.76 小時 1 次，用全寬橫幅加稀有度外框，跟通貨、珠寶的光柱分開。
- 有感保底：每小時約 1 次，用現有通貨／珠寶演出，不加新 UI。
- 離線摘要：「離開的時候」多一列：追逐物品 ×n、目前保底 n%；12 小時最多約 11 件，一列彙總。
