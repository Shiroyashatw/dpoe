## 1. 共通規則
- **兩種尺寸同級**：390×844（也要放得進 375×667）與 1280×720（只用滑鼠也能玩；1440×900 照角落錨點）。
- **顏色**：只用 token；diff 不准有 hex、`rgb()`／`rgba()` 字面值或舊 token 名（`--s0`、`--milk`、`--fr-o`、`--r4`…）。canvas 用 `PAL.xxx`。
- **style.css 同一個選擇器現在寫了好幾次**（例：`.btn` L182、L487；`.hb` L622、L713、L1919）。M2-34 時把本批元件的規則集中到檔尾一段 `/* M2-33 基礎元件 */`，前面同選擇器的外觀宣告刪掉（版面宣告留著）。
- **減少動態**（`prefers-reduced-motion: reduce`）：全部位移、縮放、滑入改成直接出現；只留 ≤ 120 ms 的透明度變化。
- **焦點**：所有可按元件 `:focus-visible` 2 px `--border-hi` 外框、外推 2 px（M2-37 §2）；不准拿掉 outline。
- **等級標記字形**：★、▲、▲大 是同一組等級標記（數值設計師），本批維持文字字形、跟所在文字同色，不轉圖示；之後要轉就三個一起轉。「記憶」用文字標，不用符號。◆ 只代表稀有、◈ 只代表傳奇；追逐記號用王印圖示 16 px（M2-29）。
