## 2. 顏色用法（美術方向 A 廟宇古地圖＋C 的用色規則）

只寫 M2-36a 的角色 token，不寫任何色值。分頁、面板、框、按鈕、底板只用低彩度的面板／框線／文字角色；彩色只給三處：追逐物（`--rar-chase`）、變強數字（`--good`）、主動作與提示（`--act`，方向 A 的銅綠）。不准用 `--rar-*`、`--el-*`、`--dmg-*` 或昇華 `--asc` 畫面板、分頁、按鈕；桌機「追逐物品」分頁按鈕照一般分頁。不用虛線。

| 用語 | 角色 token | 用在 |
| --- | --- | --- |
| 面板底 | `--panel`；直立半版 `--sheet-bg` | 所有面板 |
| 凹格 | `--panel-inset` | 王印收集格底、空格底、鍵帽底 |
| 凸起／hover | `--panel-raised`／`--panel-raised-2` | 沒選中的段與模式格、更多的列 |
| 面板框 | `--border-mid` 實線 1px | 桌機 Z2 面板一定有框（銅框九宮格 M2-33 換，畫在面板寬度內） |
| 弱線 | `--border` 實線 | 空格框、分隔線 |
| 可按元件外框 | `--border-ctl`（不當字色） | 三段切換、模式切換、開了但空著的技能格 |
| 焦點框 | `--border-hi` | Tab 焦點 2 px、外推 2 px |
| 主文字／標題／強調 | `--tx`／`--tx-title`／`--tx-strong` | 內文、標題列、靈魂數 |
| 次文字 | `--tx-dim` | 副行、「王印 {k}／4」、單色剪影 |
| 停用字 | `--tx-off` | 「沒有可以套用的印」 |
| 場景上的字 | `--tx-scene` 墊 `--plate-world` | 地點列、首領進度、狀態、HP／MP 數字、#warn |
| 主動作 | `--act` 底＋`--on-act` 字，hover `--act-hi` | 打造、套到裝備、去鍛造打一件、去營地 |
| 選中 | `--sel` 底＋`--sel-ink` 字（紙卡） | 選中分頁、選中段、模式切換目前那格 |
| 提示點、營地徽章 | `--act` 底＋`--on-act` 字，外圈 `--panel-inset` | 分頁提示點、營地「{n}」 |
| 追逐色 | `--rar-chase`（`-hi`、`-bg`、`-rgb`）；外框 `.chf` | 收集格外框、橫幅外框與第一行、保底 100% 那一行 |
| 「新」膠囊 | `.cnew`：`--rar-chase` 底＋`--sel-ink` 字 | 第一次拿到、追逐物品剛開放 |
| 橫幅底 | `--chase-bnr` | 追逐橫幅 |
| 變強色 | `--good`（`.c-good`） | 空格候選數裡有比身上強的 |
| 生命／魔力 | `--hp`／`--mp` | Z3 的條 |
