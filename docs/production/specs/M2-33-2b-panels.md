## 9. 驗收（雲端 Claude Code 無頭瀏覽器；不合併）
1. 截 375×667、390×844、1280×720、1440×900：戰利品（含選中、比較）、角色（含空格與挑選區）、鍛造三段、技能三頁、天賦樹（含說明卡）、更多、設定（含快捷鍵表）、掉落紀錄、地點清單、回營地確認、腐化確認。
