# M2-12 營地設施外觀分級表 lookTiers

負責：Game Art Director。版本 2026-11-20 12:01（台北）。依據：遊戲製作人交辦（幕僚長 11:54 轉交，B3 範圍資料、不是新批次；只出表、不換圖）。M2-36-int 換圖、B4 技能圖示仍暫停，本檔不碰素材。

用途：B3 升級儀式裡，跨過「換外觀」那一級播 1200 ms，其他級播 600 ms。程式每座設施讀一個 `lookTiers` 陣列（目前留空）。行為規格在 `M2-12-shell-part2.md` §12 第 5 點、§4 施工動畫；牌匾與單座卡在 §3。本檔只定外觀分級資料，不改費用、解鎖或程式。

讀法：`lookTiers` 列出的是「升到這一級時換階段圖」的等級。升級後的新等級落在表裡（或一次連升跨過表裡的某一級）才走 1200 ms；只加小配件、不加階段圖的級走 600 ms。

## 2. 各級外觀變化

下列只寫換階段圖那一級。中間級加的小配件走 600 ms，不進 `lookTiers`。句子是分級意圖（對齊 M2-11.1 用哪張底、M2-11.2 怎麼變大、營地氛圍禁令），不是已畫好的逐級分圖。

### 2.1 鍛造台 `forge` [1, 5, 10, 15, 20]

中間級輪流加：工具架、水槽、煤堆、小火盆、鍊條架。煙往上飄。

| 級 | 外觀變化 |
| --- | --- |
| 1 | 場景裡出現舊鍛造台本體（鐵砧與小火），作為第一張階段圖。 |
| 5 | 換成更大的鍛造棚階段圖，工作面與火光範圍明顯變大。 |
| 10 | 再換成有頂的工坊階段圖，體積再抬一層。 |
| 15 | 工坊再擴一進，結構更厚實；外觀仍是工坊，不走祭祀或喪葬意象。 |
| 20 | 最終階段圖，最大的有頂鍛造工坊。 |

### 2.2 瞭望台 `watch` [1, 8, 15, 22, 26]

中間級輪流加：地圖卷、旗桿、燈籠、望遠鏡。Lv22～26 每級在符文環加一個賽制線色光（酆都、心魔、四凶、陰兵、弒神）；這是營地裡唯一允許的冷光（camp-mood-D2（已刪） §2）。只有 22 與 26 換階段圖：23、24、25 只加光點，走 600 ms。M2-11.2 原寫「賦制線」，畫面與本檔一律用名詞表的「賽制線」。

| 級 | 外觀變化 |
| --- | --- |
| 1 | 舊地圖台加上紫色符文環，作為第一張階段圖。 |
| 8 | 台體與符文環換成更大的階段圖。 |
| 15 | 再抬高、加大一層。 |
| 22 | 換成接近最終塔型的階段圖，符文環同時加上第一點賽制線色光（酆都）。 |
| 26 | 最終階段圖，第五點賽制線色光（弒神）就位，五點齊。 |

### 2.3 斥候營 `scout` [1, 2, 3, 4]

每級都換階段圖。底是現有帳篷與紅色戰旗（M2-11.1f）。戰旗上的星數跟星級上限一致（Lv n ＝ (n＋1)★）。

| 級 | 外觀變化 |
| --- | --- |
| 1 | 1 頂帳篷，戰旗上 2★。 |
| 2 | 2 頂帳篷，戰旗上 3★。 |
| 3 | 3 頂帳篷，戰旗上 4★。 |
| 4 | 4 頂帳篷，戰旗上 5★。 |

### 2.4 民房 `house` [1, 4, 7, 10]

底在舊市集位（M2-11.1e）。中間每一級仍加一間小屋或一層，煙囪冒煙（600 ms）。

| 級 | 外觀變化 |
| --- | --- |
| 1 | 舊市集位出現第一間小屋，煙囪冒煙。 |
| 4 | 換成一小群小屋、或加了一層的階段圖。 |
| 7 | 住屋群再加密，或再加一層。 |
| 10 | 最終階段圖，最大的民房群。 |

### 2.5 長老屋 `altar` [1, 4, 7, 11]

長相改成民家小屋，不是壇：有門、窗光、屋簷，長老在門口或屋內教人（camp-mood-D2（已刪） §2；名詞表 v0.6.19）。中間級配件改為書架、卷軸架、符文板、修行墊、掛燈（取代 M2-11.2 原列的香爐、燭台、符紙、供品）。禁用祭祀與喪葬意象。

| 級 | 外觀變化 |
| --- | --- |
| 1 | 民家小屋出現（門、窗光、屋簷；長老在門口或屋內），作為第一張階段圖。 |
| 4 | 小屋加大，書房與教學空間更明顯（天賦樹解鎖的那一級）。 |
| 7 | 再換更大的階段圖，昇華石碑立在屋旁空地，不放在屋前正中央。 |
| 11 | 最終階段圖，小屋與石碑區收在最大的那張。 |

### 2.6 倉房 `store` [1, 3, 5]

底是舊倉庫（M2-11.1d）。Lv2、Lv4 只加一組木箱，不換階段圖。

| 級 | 外觀變化 |
| --- | --- |
| 1 | 舊倉庫本體出現，旁邊一組木箱。 |
| 3 | 庫房加大，木箱堆得更高、更寬。 |
| 5 | 最終階段圖，最大的倉房與成排木箱。 |

### 2.7 產生器（林場 `wood`、礦場 `iron`、獵場 `hide`、絲地 `silk`）[5, 10, 25, 50]

四座同一組等級。中間不加配件；在職居民多少，就看得到幾個人在幹活。基底外觀（林場／礦場開局 Lv1；獵場／絲地出現時 Lv1）照 M2-11.1：林場＝伐木樁＋木堆（左上樹旁），礦場＝礦口＋礦車（右側岩壁），獵場＝曬皮架，絲地＝蠶架。75 級起的里程碑（階 +1、之後每 50／100 級）不再換階段圖，走 600 ms。

| 級 | 外觀變化 | 對應里程碑（`genMs`） |
| --- | --- | --- |
| 5 | 換成第一張里程碑階段圖，場地明顯擴大。 | 產量 ×2 |
| 10 | 再換更大一張，看得見第二個工位。 | +1 工位 |
| 25 | 場地再擴大一截。 | 產量再 ×2；林場以外階 +1 |
| 50 | 第四張、也是最後一張階段圖，第三工位的空間入畫。 | 產量再 ×2、再 +1 工位 |

## 3. 工程接線用資料

解鎖表六座用 `CAMP`／`CAMP_B` 的 id；產生器四座用 `GEN` 的 id。建議做成並列對照表（不要改 `CAMP` 各列的費用資料）：

```js
/* 升到表內等級（或一次連升跨過表內某一級）→ 1200 ms 換外觀儀式；其餘 600 ms。 */
const LOOK_TIERS = {
  forge: [1, 5, 10, 15, 20],
  watch: [1, 8, 15, 22, 26],
  scout: [1, 2, 3, 4],
  house: [1, 4, 7, 10],
  altar: [1, 4, 7, 11], /* 畫面名：長老屋 */
  store: [1, 3, 5],
  wood: [5, 10, 25, 50],
  iron: [5, 10, 25, 50],
  hide: [5, 10, 25, 50],
  silk: [5, 10, 25, 50]
};
```

這是 B3 範圍裡的資料，不是新批次。接進現有升級儀式即可。本檔不換圖：沒有階段圖的建築，仍照 M2-12 P2-5 用數字翻牌＋塵土，不另生成。
