## 4. 無輪結束畫面（連續感）
- 換波：0 ms，介面任何東西都不動、不出字；下一波從畫面邊緣進場。
- 王出現：橫幅 44 高「{王名}現身」，停 800 ms 後 240 ms 縮成王血條（ease-out），不蓋戰場中間；觀戰時一樣。

## 10. 無障礙
- 減少動態：鏡頭不推、慢動作關、所有滑入改 150 ms 淡入、去色改字板。
- 關畫面震動、關手機震動兩個獨立開關。
