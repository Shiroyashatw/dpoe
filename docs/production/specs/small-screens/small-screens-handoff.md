工程要點：

- **配色**：照第 1 份 §2 對照表。按鈕內第二行（鍵位、副標）用 `--tx`，不可用 `--tx-dim`（`--btn2` 上 3.70:1 不及格，PR #213 教訓）。更多格懸停只換邊色、不換底。
- S02 觸發判斷：驗證成功且雲端存檔 v≥10 且本機有訪客進度（有任何角色經驗或倉庫物品）才出卡；取消要登出回訪客並保留本機存檔。
- L01：`LOGN.mid` 顯示字改「裝備」；`frac`／`mem` 改文字「破裂」「追憶」。存檔內的鍵不改。
- M01：`moreHTML` 移除 `chase` 項；`Y` 鍵行為不動。
- T02：背景用 `<img>` 或 CSS background，`object-fit: cover`；遮罩是獨立一層 `rgb(0 0 0 / 0.62)`，不可調淡；壓圖文字只用 `--tx-strong`／`--tx`。圖未到前底色 `--panel-inset`。

## 2. 給美術總監（T02 背景圖）

- 尺寸 1280×720（建議另交 1280×800 出血版給 Steam Deck；或接受 cover 上下各裁 40）。
- 中央安全區 360,232 560×208 會壓標題與「開始」：避免高頻細節、亮點、細線、文字狀紋理。
- 全畫面會疊 62% 黑遮罩：最亮純白經遮罩為 `#616161`，`--tx-strong` 仍有 5.90:1。若想讓圖更亮，請在安全區外處理，不要求減遮罩。
- 圖內不要放字（標題與按鈕由程式畫）。
