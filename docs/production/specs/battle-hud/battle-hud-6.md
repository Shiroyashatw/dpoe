## 23. 危急紅邊（取代「低血紅邊」）

依數值設計師〈低生命紅框：改看生命＋能量護盾（定案 v1.0）〉（mumi 2026-11-21 12:22 定；檔案在數值設計師工作區 `docs/production/adjust/低生命紅框.md`，**未進 repo**）。引文照原文：

- 名稱：「設計文件名稱「危急紅邊」；沒有畫面字，程式 id 不改」（§0 題 4）。EN Danger vignette。元素 `.bh-vig`（id `bhVig`），`aria-hidden`；不叫「貧血」（「貧血跟紅框分開；貧血維持生命 < 35%（LOW），天賦不動」§0 題 1）。
- 條件：「紅框一級：(生命＋能量護盾)／(上限合計) < 35% **或** 生命 < 35%（讀 LOW）；二級：任一 < 20%；常亮、不脈動，強度照 PR #146（60%／70%）」（§0 題 2）。
- 異能魔力：「點了「能量護盾保護魔力」時，能量護盾不算進合計（目前值與上限都當 0），因為它不擋傷害（skills.js:1845）。」（§4.1）
- 「沒有能量護盾上限（含豐血、純生命）時，合計＝生命比例。」「不加滯後（回到門檻上就熄）」（§4.1）
- 生命條外框：「生命條外框 `bhLow` 跟紅框同一個條件」（§4.1）。本規格同時把外框改成常亮不閃（舊寫法「閃 ≤2 次／秒」作廢；照 12:37 核准示意圖）。
- 藥劑：「藥劑只補生命，這兩個建議維持只看生命」（§1.2：生命藥劑鈕呼吸外框、自動喝藥 `AI_HP = 0.5`）。
- 流血、中毒「這輪不另外提早亮」（§0 題 5）。

## 24. 能量護盾怎麼運作（參考；數值歸數值設計師，以程式為準）

- 擊中先扣能量護盾，剩下扣生命。
- 4 秒沒受傷才開始充能，每秒 12.5%；受傷重新計時（skills.js:2042–2049、1846）。
- 流血、中毒跳過能量護盾（combat.js:1990–1994）；所以流血時可能能量護盾滿、生命快見底，危急紅邊靠「或生命」那條亮。
- 點了異能魔力（能量護盾保護魔力）：擊中不扣能量護盾，能量護盾先替魔力付費。

## 27. 畫法

- 細條在生命條 1 px `--border` 框內最底 3 px：390 x 11–352、y 522–524；1280 x 341–788、y 668–670。先畫生命條 `--hp` 填色，再畫細條（空槽 `--panel-inset`＋`--es` 填），最後畫字。
- 前緣 2 px `--es-hi` 貼在 `--es` 填色最右邊，只在充能中；滿了、被打掉後 4 秒延遲中、0 時都不畫。
- 能量護盾 0：只剩空槽。沒有能量護盾上限：整條不畫，生命條跟 v1.3.5 一樣。
- 不可點；細條不加框、不加刻度（ES4）。

## 29. 驗收

1. 拿能量護盾裝：生命條底出現細條，字變「生命 … / …・能量護盾 … / …」；卸下：細條消失，字回「生命 … / …」。
2. 被打：細條先縮、生命不動；細條 0 後才扣生命。
3. 停止受傷 4 秒內細條不動、沒有前緣；4 秒後開始長，前緣 2 px 亮、不閃；中途再被打，前緣消失、重新計 4 秒。
4. 流血、中毒時細條不動。
5. 危急紅邊：照 §23 兩條任一成立就亮；流血把生命打到 < 35%、能量護盾滿也要亮；點了異能魔力時只看生命。紅邊與生命條外框常亮不閃。
6. 生命藥劑鈕呼吸框、自動喝藥只看生命。
7. 點了異能魔力：細條仍在生命條（E2）。
8. 1280 點經驗條右端 x 789–790：算魔力藥劑（E3）。
9. 收起：390 細條跟 HUD 下移 140；1280 不動。
10. 全部未驗（遊戲沒開；只有規格產生器畫的示意圖）。
