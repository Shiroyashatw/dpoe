## 11. 技能格

**尺寸**：390 是 44×44（生命條上方，間距 6：x 10＋i×50）；1280 是 48×48（間距 8，左上鍵帽 14×14、字 12）。底 `--panel-raised`、1 px `--border`。格內件從 R4 §3.2（52／56）等比縮，座標以格左上為原點：
- 右上數字盒：44 → x 27–42、y 2–18；48 → x 29–46、y 2–21。蓄力「2/3」盒加寬：44 → x 15–42；48 → x 17–46（讓出鍵帽）。字 14/700（390）、16/700（1280），`--tx-strong`。
- 彈匣格：4×4、間距 2，6 格寬 34；44 → x 5–38、y 36–39；48 → x 7–40、y 40–43。可用 `--prog-hi` 實心、用掉 1 px `--border-mid` 空心（合併前暫用 `--fr-hi`），格群有 `--s0` 底板（R4 §3.1）。
- 儲存點：7×7、間距 3；44 → x 13–19／23–29、y 30–36；48 → x 15–21／25–31、y 34–40。下緣 2 px 進度條（下一顆）。
- 蓄力弧：格外 2 px 一圈 2 px 線，平均 3 段、段間 4 px，從正上方順時針；未到 1 px、到了 2 px；蓄滿外框 `--border-cap` 120 ms。
- 冷卻：灰幕由上往下收；中間秒數 16/700、1 位小數。

|---|---|---|

**數字算法（數值設計師 11/20，定案）**
- 藥劑技能格上 {n}＝`floor(P.flask ÷ flaskCost())`（hud.js:300）。
- 工具提示 {c}＝`flaskCost() × FLASK.chg`，範圍 1.25–10；**無條件進位到小數 1 位，去掉尾巴 .0**（例：10、7.5、3.8、1.3）。
- 彈匣格數＝`max(P.ammo[k].n, clipOf(D))`；儲存上限＝`D.gren[0] + ST.grenUse`；段上限＝`D.charge.max`，目前段＝`seg()`（R4 §3.2）。

**規則**
- 格上數字只寫整數、不寫單位；秒數 1 位小數，不寫 ms；單位只放工具提示。量詞：發 rounds、顆（EN 不寫）、段 stages、次 uses。禁用「彈夾」；彈藥相關處不寫「充能」。
- 生命、魔力藥劑鈕只畫冷卻環（2 px `--hp-hi`／`--mp-hi`＋1 px #000），不寫次數、不寫秒數。390 看得到 20、熱區 44；1280 看得到 22＋鍵帽、熱區 36。掛機時自動喝。
- 自動模式蓄力須蓄滿才出手（既有；mumi 11:38 Q1 修 AI 對齊，未驗）。
- 互動：390 點技能格＝開技能分頁並捲到那一招（M2-40 §4）；長按 400 ms＝工具提示 P14（10–380 × 392–426，放開收）。1280 hover＝工具提示 D19（x 從該格 x 起、寬 328，超出 1272 就往左推；y 524–558）；點＝開技能分頁。
- 工具提示暫時蓋住中央 60% 下緣和掉落牌，可以接受（只在長按／hover 時出現）。

## 13. 驗收（實機截圖疊示意圖）

1. **截圖**：同 CSS 視窗尺寸、DPR 1（或 DPR 2 對 `@2x`），工程師用雲端 Claude Code 拍，結果貼 PR 留言。
2. **疊圖**：`*_overlay.png` 100%、左上對齊 (0,0) 疊上截圖；只有 hud 元件與掉落牌下限線的框線和 id，沒有場景填色。
3. **容差**：每個框四邊 ±2 px。表上每個 hud 元件逐項打勾：位置、尺寸、字級／字重（computed style）、token（computed color 對 token 值）、熱區（`getBoundingClientRect`）。場景示意只驗規則（掉落牌 y 下限、記號、光柱）。
4. **判定**：任何一項不符＝退回，不 merge；不准「先 merge 再修」。判定人 UIUX設計師。上色版 mumi 16:32 已核准。
5. **必交截圖**：5 狀態 × 2 尺寸＝10 張原圖＋10 張疊圖；mumi 實機尺寸確定後再加（＋疊圖，該尺寸的 overlay 由 UIUX 另出）。
6. **必交影片**：裝填（技能格 1 從 1 發打到 0 → 裝填環 →「裝填」→ 補滿，兩尺寸）；蓄力（按住 0→1→2→3 段、蓄滿外框 120 ms、放開清掉；自動模式蓄滿才出手）；收起／展開（▼ 或下拖 → 200 ms 滑 → 戰場一次改高；▲ 或點列展開）；最近一筆掉寶從右滑入 200 ms 後停住（不做連續滾動）。
7. **做狀態**：`DBG.ammo(k, n)`、`DBG.gren(k, used)`、`DBG.stage(k, s)`（R4 §3.3）；王戰、低血、掉落洪水、光環數用工程師現有的 DBG 掛鉤（名稱未驗）。
8. **文字掃描**：畫面上沒有「彈夾」；彈藥相關處沒有「充能」；沒有祭壇／祀壇／祝壇／祥壇／Altar（用「長老屋」）。
