# M1-08 輔助與孔的規則與文案

> 現行規格，只放目前有效的內容；決定與調整記在 [`CHANGELOG.md`](../CHANGELOG.md)。

完成，待開發實作。依 repo：`docs/企劃書.md` 6.2、`js/data.js` `CAMP.altar`、`js/items.js` L133、L351。以下文案原文照用，不得改寫。

| 規則 | 內容 |
| --- | --- |
| 技能與輔助不是道具 | 0.2.75 起是目錄，不會掉落；拿著這把武器，能用的技能與全部輔助都在清單裡 |
| 技能格 | 開局 1 格；祭壇 Lv1 第 2 格、Lv3 第 3 格、Lv6 第 4 格、Lv9 第 5 格 |
| 輔助孔 | 開局 0 個；祭壇 Lv2 每一招第 1 個、Lv5 第 2 個（同時開光環欄）、Lv8 第 3 個、Lv11 開到 5 個；實際孔數＝技能自己的孔數與祭壇上限取小（`soN`） |
| 同類限制 | 同一分類的輔助不能同時插在一招上 |
| 裝備上的「孔 ○」 | 是符文孔，符文還沒做；0.5.5 先不顯示 |
| 角色面板的寶石格 | 0.2 的殘留，拿掉 |

| 出現的地方 | 文案 |
| --- | --- |
| 已開、空著的技能格 | 點這裡挑一招。技能不會掉落，這把武器能用的招都在清單裡。 |
| 下一個要開的技能格（Q10 C） | 升祭壇到 Lv n，開第 m 格技能。 |
| 還沒開輔助孔時（下一個） | 升祭壇到 Lv2，每一招多 1 個輔助孔。 |
| 空著的輔助孔 | 點這裡插一顆輔助。輔助不會掉落，目錄裡的都能用；同一類只能插一顆。 |
| 被祭壇上限蓋住的孔 | 這一孔要祭壇 Lv n 才生效。 |
| 第一次開輔助孔（提示） | 祭壇 Lv2：每一招多了 1 個輔助孔，到技能分頁插一顆輔助。 |
| 全遊戲用詞 | 「技能寶石」一律改成「技能」，「寶石」只留給天賦樹的珠寶。 |
