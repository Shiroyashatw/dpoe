# AI 試玩回歸報告範本（版本守門）

> 現行規格；什麼時候要附見 [`docs/本機執行.md`](../../本機執行.md)「版本守門」。門檻只看 [`M2-03-addictiveness-criteria.md`](M2-03-addictiveness-criteria.md)，本範本不另訂門檻。

## 怎麼用

1. 先開本機伺服器：`python3 -m http.server 8000 &`。
2. 在自己的分支跑 `node tools/ai_report.js evidence/<代號>`（約 2 小時；某尺寸失敗就再跑同一個指令，只補失敗的）。不用為了跑報告改 `VER`。
3. 改經濟的 PR 另跑 `node tools/loot_check.js` 兩次（固定亂數，幾秒跑完）：一次在分支起點的 main（`git stash` 或另開 worktree），一次在自己的分支，參數相同。
4. 複製下面「範本」整段貼進 PR 說明，把 `<…>` 換掉；`A1-A10.md` 整份貼進「指標表」。
5. 「對照」找上一份合併進 main 的報告（最近的 `evidence/*/A1-A10.md`，或上一個版本 PR 的說明）。
