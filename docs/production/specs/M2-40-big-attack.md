# M2-40 大招判定（戰鬥 HUD 警示）

版本 v1.0｜數值設計師｜依 main c4b1a1d｜行號都是這個版本

## 1. 判定（一句）
**大招 ＝ 出手的是王（`m.boss`）且 這招的預警 ≥ 0.6 秒 且 傷害倍率 ≥ 1.2。**
- 「王」包含地圖王、生肖王、酆都四王與閻羅、心魔劫七情王（`b.boss = b.mini = 1`，game.js:582）、四凶、將領、太歲與所有 Uber。小怪與菁英一律不算（菁英只有前搖 ×0.85、傷害 ×1.5，game.js:1474、data.js:8493）。這跟 AI「只躲王」的規則一致（ai.js:90）。
- **預警**：從出招開始，到玩家看得到落點的第一次傷害為止的時間。有預警圈的招取第一個圈的 `dur`，沒有圈的招取前搖 `BOSS_WIND`（game.js:1609–1640）。
- **傷害倍率**：這招每次擊中的傷害除以王自己的 `m.dmg`。王的 `m.dmg` 已含 `BOSS_DMG` 1.44（combat.js:31、game.js:634）與 Uber ×1.5，所以這個倍率不受階級影響。
- 判定用基礎時間（rage＝1），只有七情王「怒」的暴怒會讓前搖 ×0.65（game.js:1652），被判成大招的招在暴怒時一樣標。**警示持續時間用實際值**（含 ×0.65）。
- 不用「傷害佔主角生命％」：那要先跑 hurtCalc（護甲、抗性、閃避都要算），而且會隨階級和裝備變動，不穩定。之後若要加「會致命」的紅色等級，再另外用即時 `P.mhp` 和 hurtCalc 的結果評估，門檻得用雲端驗算來定（這份規格不定）。

## 3. 套用結果：5 招
衝撞、生死簿・判決、勾魂鎖鏈、饕餮吞噬、太歲輪值。其中饕餮吞噬目前不會出（§5），所以實際會標的是 4 招。

會出大招的王，以及大招在王可選的招裡佔幾招（王每次在距離允許的招裡平均挑一招，距離 <140 用近表，否則用遠表，game.js:1727–1733）：
- **衝撞**（只在遠距離出）：虎姑婆 1/3、牛頭 1/2、馬面 1/2、骨巨人 1/3、饕餮 1/2、燭龍 1/3、窮奇 1/2、檮杌 1/2、怒 1/3、欲 1/1、下尸 1/4、刑天 1/3、蚩尤 1/4、燭九陰 1/5、涿鹿兵主 1/10，以及生肖王的牛 1/2、虎 1/2、馬 1/3、雞 1/3、狗 1/2、豬 1/3。
- **判決**：上尸 近 1/4、遠 1/4。
- **衝撞＋勾魂**：中尸 遠 2/4。
- **衝撞＋判決＋勾魂**：十殿閻羅 近 1/6、遠 3/9；三彭 近 1/5、遠 3/9。
- **輪值**：太歲、太歲星君 近 1/4、遠 1/4（當值的神借來的招另外加進去，會變動）。

**頻率**（只寫資料直接讀得出的）：王兩招之間的間隔＝預警＋收招（0.2～0.9 s，衝撞是衝 0.42＋收 0.55）＋冷卻 rnd(0.5,1.1)×1.3＝0.65～1.43 s（game.js:2005–2009）。一次衝撞從出招到下一招可以出，要 2.37～3.15 s。要換算成「每分鐘幾次」，得先知道玩家在近、遠距離各待多久，這要雲端模擬（§6）。

## 4. HUD 要的欄位
在出招當下判定（game.js:1733，`m.t` 剛設好；燭龍睜眼不在名單上）。不能等預警結束才判。
```
big = m.boss && isBigPat(m.pat)
// isBigPat：只給這 5 招 true；由 §1 的布林式導出，check.js 要驗證
warn = { src: m, pat: m.pat, t0: G.t, dur, end: G.t + dur }
```
- `dur`（實際值，含暴怒）：衝撞＝`m.t`；判決＝那個圈的 `dur`（2.1×rage）；勾魂、吞噬、輪值＝`m.t`。
- **警示持續＝預警時間**：`G.t ≥ end` 或 `m.hp ≤ 0` 時收起。勾魂後面接的 0.5 秒砸地不另外警示。
- 只在目標是玩家時顯示（`T === P`，被魔像嘲諷時不顯示）。輪值和吞噬是以王為中心的範圍招，照樣顯示。
- 同一時間只顯示一則。新的大招只有在它剩下的時間比目前這則長時才取代（心魔劫第 2 波的七情王有可能和地圖王同時在場）。
- 剩餘比例可以給倒數條用：`(end - G.t) / dur`。390×844 和 1280×720 用同一組欄位，版面由 UIUX 決定。招名不在資料裡（只寫在註解），所以 HUD 不要依賴招名，要顯示名字的話先收進名詞表。
- 驗收（check.js）：
  - 5 招判 true，其餘王招和所有小怪、菁英判 false。
  - 暴怒時衝撞的 `dur` 是 0.4875。
  - 被魔像嘲諷時不顯示。
  - 王死掉時警示立刻收起。
  - 在 390×844 與 1280×720 各截一張圖，畫面上要同時有判決圈和警示。

## 5. 發現（不在這份規格裡改）
`BOSS_NEAR`／`BOSS_FAR`（game.js:1570–1608）沒有收 devour、gale、unstop、chaosjump、daynight。挑招時只從這兩張表裡挑（1727–1730），所以四凶和燭龍的招牌招在 c4b1a1d 上不會出現，燭九陰也一樣。要不要補進去是玩法決定。補進去以後，吞噬會自動被標成大招，其他 4 招不會。

## 6. 暫定與待決
- **倍率門檻 1.2（暫定）**：用意是讓警示稀少。如果改成 1.0，砸地、惡的彈開、連爆線、十殿輪轉、燭龍睜眼都會被標進來，很多王的遠距離招會有一半以上被標（例：魔神仔 2/3、骨巨人 3/3、惡 2/2）。由製作人決定。
- **0.6 s 的預警門檻**沿用製作人的定義。被暴怒縮到 0.49 的招照樣標（判定用基礎時間），這點請製作人確認。
- **每分鐘大約幾次**要雲端驗算：讓 AI 自動打各王 10 場，記錄近／遠距離的時間比例和每次大招的時間點。
- **名詞**：名詞表 v0.6.6 沒有「大招」，也沒有「預兆」。注意「預兆」已經是心魔劫的掉落物名稱（data.js:7648、game.js:1113），HUD 的危險提示不要用「預兆」。建議用「大招」和「預警」（程式註解裡已經用「預警圈」），由名詞表任務決定要不要收。
