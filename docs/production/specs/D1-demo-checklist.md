## 量法與門檻

| 項目 | 說明 |
| --- | --- |
| 尺寸 | 390×844（另驗瀏覽器實際可用高度，例 390×664，估計值，實測值未驗；原 PWA 390×763 已取消（mumi 11/21 12:42））與 1280×720（另驗 1280×800 ×1.25）；每列兩尺寸各一張 |
| A 門檻 | 熱區 ≥ 44 pt 直立／≥ 32 px 桌機／Deck 觸控 ≥ 60 px、游標／觸控板 ≥ 40 px；間距 ≥ 8；字直立 ≥ 14 pt、桌機 16／14 px；對比 4.5:1（大字、圖示 3:1）；場景上的字有底板；安全區；裁字、重疊 0 |
| C 門檻 | 1 秒掃視；每屏前三層級；HUD 貼邊；數字不蓋敵人；同元件同樣子 |
| D 門檻 | 下一個目標一直看得到；掉落分級（顏色＋記號＋聲音強度） |
| 字級量法 | 依角色判：標籤白名單（分頁字、鍵帽、徽章、`#prog b`、篩選字）≥ 12；條內數字 ≥ 12；正文直立 ≥ 14、桌機 ≥ 16；門檻從 `:root` token 讀 |
| 對比量法 | 只留下限 4.5（大字、圖示 3），不設上限；背景取字形外 8 px 環、最亮 10%；每個 token 配對只算一次 |
| 熱區量法 | `elementFromPoint` 4 px 格點量實際可點；相鄰 ≥ 8 只比兩個都 < 52 寬的熱區；段落內 `.term` 豁免但列出 |
| 重疊量法 | 全輪去重，只記跟可點或資訊元件的交集；刻意疊放（抽屜蓋戰場）列白名單 |
| 圖示 | 只用 1 或 2 倍整數；同畫面同選擇器記 1 筆，寫顯示寬／原寬 |
| 標記 | 「要錄影」＝60 fps 逐幀，兩尺寸，一般＋減少動態各一次；「demo 未驗，進遊戲量」＝假戰場量不準 |
