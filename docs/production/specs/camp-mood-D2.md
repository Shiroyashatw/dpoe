# 營地氛圍規格（D2 紙紮灰燼）v1.1

2026-11-19 17:25（台北時間）｜UIUX設計師｜給 Game Art Director 出圖、我審圖用。v1.0 16:50。
起因：mumi 看 D2 營地示意圖說「直接變成出殯風」，所以營地要先有氛圍規格再出圖。介面色票（palette-D2-final-ui.md v1.4）、UI token、面板不動，本規格只管**場景層**：光、道具、居民、天空、地面明暗。
數字標「起點」的是第一版目標，量過可調，調整後寫回本頁。
v1.1：§4 平均 L* 改成「光圈內比戰場場景高 ≥6、場景整體跟戰場差 ±4」；§6 固定設施與串燈豁免 120 px 規則，地面道具不得進主角 72 世界 px，主角對比須為前 3 名；§2／§2b 加試招場禁用石圈與稻草人。

## 1. 情緒定位（一句話）
**「刷完回來的家」：天黑了，外面是灰燼荒野，營地裡有火、有人在忙、有飯香。**
玩家每次回營地都是剛刷完一輪、準備升級和換裝。這裡是整個遊戲唯一**安全、溫暖、熱鬧**的地方，要讓人想多待幾秒，看自己蓋起來的東西。
- 要有的三個感覺：安全（被圍起來、有光）、溫暖（火與食物）、有生氣（人在動、東西在冒煙／晃）。
- 五秒測試：看一張營地截圖 5 秒說出三個形容詞，要落在「溫暖／熱鬧／安心／家／收工」這一類；出現「冷清／肅穆／喪／祭／陰」任一個就不過。
- 跟 D2 世界觀的關係：紙紮灰燼是**外面**的語言（荒野、敵人、戰場）。營地是人類守住的據點，用的是「木、布、火、食物、工具」，不用紙紮。

同類參考（取它的做法，不抄畫面）：
- Hades 的冥府大廳：冥界主題，但大廳用暖燈、熱鬧的 NPC，讓人覺得是家。這是最接近的範例：死亡題材的遊戲，據點仍然溫暖。
- Torchlight II 營地：暖色篝火、帳篷、攤販，跟外面野地形成明暗對比。
- Last Epoch 的時間盡頭（End of Time）：安全區有明確的光源中心。
- 反例：Darkest Dungeon 的小村（刻意陰鬱）、Diablo IV 的 Kyovashad（冷灰），dpoe 營地不走這條。

## 2. 禁用意象（喪葬、祭祀，一律不出現）
場景層任何地方都不能有：
1. 白燈籠、白紙燈、白布、白幡、黑白對比的布條；燈籠一律暖色布或木框（例 #b98a5e 一類）。
2. 紙錢、冥紙、紙紮人／紙紮屋、金銀元寶堆。
3. 香爐、插香、燭台成排、供品盤（水果／饅頭堆疊）、靈位牌、遺照式的框。
4. 對聯式的直式長條字布、輓聯、門口對稱擺設；**整體構圖不可以左右對稱**（對稱＝靈堂）。
5. 菊花、白花圈、花圈形的環。
6. 棺木、墳丘、墓碑形狀的石碑；石碑（昇華石碑）要做成**有符文發光的工作石**，頂部不可是圓拱墓碑形。
7. 飄落的灰燼、紙屑、煙霧往下沉的效果（營地的煙要**往上飄**，從煙囪、鍋子、鍛造台冒出）。
8. 烏鴉、骨頭擺件、骷髏裝飾（現有 NPC crow、bone 在營地內拿掉或換成狗／貓／雞一類）。
9. 冷白或青白光源；營地裡除了瞭望台五個賦制線光點外沒有冷光。
10. 試招場不用石圈（像花圈）、不用稻草人（像墓十字），改用低武器架。
附帶：「祭壇」已由數值設計師改名「長老屋」（EN Elder's Hut，名詞表 v0.6.19；「祭壇」「祀壇」畫面禁用，程式 id altar 不變）。外觀改成**民家小屋**，不是壇：有門、窗光、屋簷，長老在門口或屋內教人。升級配件（M2-11 表「香爐、燭台、符紙、供品」）全部換成「書架、卷軸架、符文板、修行墊、掛燈」一類的教學與工作配件。昇華石碑（Lv7）立在長老屋旁邊的空地，不放在屋前正中央。

### 2b. 舊營地示意圖為什麼像出殯（美術總監自查，當反例）
以下九點在新圖裡都不能再出現，審查逐條對：
1. 所有道具壓到同一色相、C* ≤ 6，木、沙、紅旗、布、陶罐全變一種灰。→ 新圖的木、布、陶、食物要保留各自的固有色（木頭暖棕、布有一兩種低彩色，例如褪紅、土黃），只壓飽和度，不統一色相。
2. 營火用紙白 #f4f0ec 染色，看起來像白燭。→ 火一律用火的顏色（黃→橘→紅的漸層），火焰核心才允許 C* > 40。
3. 沒有暖光源，整張平光，唯一的光是紙白。→ §3 主光源＋3 個次光源。
4. 天空的淺灰亮區正好在石碑後面，像靈堂背光。→ 石碑後面不可以是全畫面最亮的區域；最亮的區域是篝火。
5. 鏡頭置中石碑，兩側凳子、台階對稱，主角站在碑前像弔唁。→ 構圖中心是篝火，石碑偏離畫面中線至少畫面寬的 15%。
6. 一排白罐，像骨灰罈。→ 容器要混搭（桶、籃、袋、罐），顏色不白，不排成一列。
7. 村民少、去色，站成一排不做事。→ 居民分散、在做事（搬柴、打鐵、煮飯、坐火邊），有 M2-11.3e 的 3 種配色。
8. 中央大片空石板，1280 下方 110 px 全黑。→ 中央地面要有材質變化（泥土、草、踩出來的小路）；畫面任一邊不能有超過 48 px 的全黑帶（L* < 5）。
9. 淺色道具亮部 L* 接近 85，看起來發白。→ 場景層道具亮部 L* ≤ 70，只有火焰核心例外。
10. 試招場用石圈（像花圈）或稻草人（像墓十字）。→ 改用低武器架。
戰場也有同一類問題（對稱白燈籠、紙白光暈），已改成 #b98a5e 和 #d9a774 16%，審戰場時一起看。

## 3. 要有的元素
每張營地圖（390×844 與 1280×720 各一張）至少要看得到：
| 類別 | 最少數量 | 例子 | 為什麼 |
|---|---|---|---|
| 主光源 | 1（篝火，在主角站位附近） | 篝火＋圍坐的木頭 | 安全感的中心，居民閒晃的點 |
| 次光源 | 3 | 民房窗光、鍛造台火、掛燈 | 讓光散在營地各處，不是一團亮其他全黑 |
| 生活跡象 | 3 | 煮鍋冒煙、晾衣繩、柴堆、木桶、動物 | 有人住、有生氣 |
| 會動的東西 | 3（示意圖用位置標出） | 火焰、煙往上飄、布旗被風吹、居民走動 | 活著的畫面；動作要慢（週期 ≥1.5 秒），不搶戰鬥以外的注意力 |
| 圍起來的邊界 | 1 | 木柵欄、岩壁、帳篷圍一圈 | 安全＝外面進不來 |
| 一點綠 | 1 | 盆栽、菜圃、藤蔓 | 對比外面的灰燼荒野，說「這裡有東西在長」 |

## 4. 光與色的量化目標（起點）
量法：從原圖用 Python 量，CIELAB；「場景層」＝去掉 UI 面板、名牌、HUD 的像素。
| 項目 | 目標 | 理由 |
|---|---|---|
| 光圈內平均 L* | 比同尺寸滿血戰場圖的場景平均 L* 高 ≥ 6 | 「外圈壓暗、光圈亮」才是回家感；整張拉亮只會又變灰（17:25 裁定） |
| 場景平均 L* | 跟同尺寸滿血戰場圖的場景平均 L* 差在 ±4 內 | 營地仍是夜晚，不要變白天，也不要比戰場整張更暗或更亮超過 4 |
| 暖色像素佔比（h 30°–80° 且 C* ≥ 8） | 25–45% | 一眼看出是暖的；超過 45% 會變成一片橘，UI 的傳奇橘會被吃掉 |
| 冷色像素佔比（h 180°–300° 且 C* ≥ 8） | ≤ 5% | 冷光＝陰，營地不要 |
| 暖光圈面積 | 主光源光圈 ≤ 畫面 35%；全部光圈加總 ≤ 50% | 光要有範圍，光圈外的暗才有安全感對比 |
| 32px 區塊 C* > 12 佔比 | 光圈外 ≤ 15%；光圈內豁免 | 已於 16:41 裁定 |
| C* > 40 像素佔比 | ≤ 1%（只准火焰核心） | 高彩只給火；不跟傳奇、追逐撞 |
| 火光色對傳奇 #fa8915 的 ΔE00 | ≥ 10（含紅綠色盲模擬 ≥ 8） | 掉落在營地出現時（倉庫、寶盒）傳奇橘要分得出來 |
| 火光色對追逐 #0cf6ee、主鈕 #7c5729 | ΔE00 ≥ 15 | 主鈕是畫面唯一的主要行動 |
| 地面 ÷ 面板對比 | ≥ 1.5 | 面板要從場景浮起來 |
| 名牌字對名牌底 | ≥ 4.5（光圈內也算） | 規格 A 條 |

## 5. 跟戰場的對比
| | 戰場 | 營地 |
|---|---|---|
| 溫度 | 冷灰、灰燼、低飽和 | 暖、火光、木頭 |
| 光 | 平均、平光，敵人與預警才亮 | 有明確光源，光圈外暗 |
| 動態 | 快、多、危險 | 慢、少、安心 |
| 構圖 | 開闊，中央留給戰鬥 | 圍起來，中央是篝火與主角 |
| 聲音（給之後的音效清單） | 打擊、怪叫 | 柴火劈啪、鍋子、遠處說話聲，音量比戰場低 |
切換時要感覺到「回家了」：從戰場回營地，第一眼是外圈較暗、光圈較亮，暖色佔比也要明顯變（§4 光圈內 L* 與暖色佔比）。

## 6. 不能動的東西
- UI 層：palette-D2-final-ui.md v1.2 的所有 token、面板、名牌樣式（M2-11.4b）、主鈕。
- 主角站位：位置固定的設施，和掛在上方的串燈，可以豁免「半徑 120 世界 px 不擺道具」。地面上的道具不能進到主角站位半徑 72 世界 px（一個主角高）內；主角跟周圍的對比要是整張圖前 3 名（主角要一眼找得到，17:25 裁定）。
- 設施位置照 M2-11.1，不搬家；只換外觀與道具。
- 像素密度照 M2-11.2d（1 格＝1.35 世界 px，不非整數縮放）。M2-11.2d「不引入新的飽和色」改成：允許本規格 §3 的一點綠與 §4 範圍內的暖色。
