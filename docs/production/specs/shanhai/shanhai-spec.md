## 0. 範圍與取代關係

- 本版只定 **1280×720 桌機**。390×844 不出圖，只跑自動化檢查（不溢位、不裁切、不遮擋；見 REVIEW-CHECKLIST）。

## 5. 互動與手感

### 5.1 開王場＝直接點擊（定案）

- 滑鼠左鍵、觸控點一下、鍵盤 Enter、手把 Ⓐ：資源足夠就立刻扣碎片並進場。**禁止**套用 `holdAsk`。
- 從按下到扣碎片／關面板／進場，應在下一幀內開始（目標感知 < 100 ms）；不要插入確認卡或延遲動畫。
- 不足：鈕 disabled，點了沒有動作（或焦點在停用鈕上按 Enter 無效果）；不彈 `hudWarn`（缺項已寫在鈕上）。
- 規則與名詞提示「首領碎片」都要寫「倒下不退」。

### 5.2 拆解神格＝0.6 秒長按（既有 `holdAsk`）

- 標題「拆解？」、說明「拆成 200 靈魂。」、紅字「⚠ 不能復原」、操作「外圈 0.6 秒填滿才執行；提早放開＝取消」。
- 左「長按拆解」160×40（`--bad`，熱區 160×44），右「取消」160×40（`--act`，預設焦點）。卡 400,220 480×250。畫面不寫「600 ms」。
- Enter／Ⓐ 按住 0.6 秒才執行；Esc／Ⓑ／取消＝關閉。裝著的不能拆（`ghSalvage`）。數字暫定。

### 5.3 鍵盤、滑鼠、手把

| 操作 | 鍵盤／滑鼠 | 手把 |
|---|---|---|
| 開關本面板 | J；更多選單「山海寶盒」 | 從更多進入 |
| 關閉 | Esc；點 × | Ⓑ |
| 五區與碎片格 | 方向鍵；點 | 十字鍵 |
| 心魔多選 | 空白鍵／點切換 | Ⓐ 切換勾選 |
| 開王場 | Enter（立即） | Ⓐ（立即，不長按） |
| 開神格管理 | 點「管理神格」；快捷欄 Enter | Ⓐ |
| 裝上／卸下 | Enter／點 | Ⓐ |
| 拆解 | 開長按卡後按住 Enter 0.6 秒 | 按住 Ⓐ 0.6 秒 |
| 名詞提示 | 停 0.4 秒 | R3 |
| 焦點環 | 2px `--sel-edge` | 同左；不擋住格子文字 |

焦點順序：關閉 → 五區（上到下、格左到右）→ 右欄兩顆開啟鈕 → 管理神格。小視窗打開時焦點鎖在窗內。

### 5.4 音效與震動

| 事件 | 音效 | 震動（手把／觸控，可關） |
|---|---|---|
| 選區、選格、開關面板、裝卸神格 | 既有 `sfx('click')` | 輕短震 10–15 ms |
| 開王場成功 | `sfx('click')`，接著進場既有地圖音；**不加**第二聲確認音 | 一次中短震，不延長 |
| 開王場鈕停用 | 無 | 無 |
| 長按拆解進行中 | 沿用 `holdAsk` 既有回饋 | 持續輕顫，放開即停 |
| 拆解成立 | 既有確認完成音（若有）＋ `click` | 一次較重短震 |
| 名詞提示出現 | 無（或極輕，不搶） | 無 |

減少動態／關閉震動時只保留必要音效。

## 7. 異常與邊界

- 五區全空（早期）：面板可開，格子全是 ×0 虛線，開啟鈕全停用並寫缺項；不鎖入口。
- 神格 0／30：快捷欄寫「身上裝備：無」與「神格 0／30」，仍可開管理窗，空狀態一句「太歲、太歲星君掉的神格放在這裡」。
- 神格滿 30：新掉的換成 500 靈魂（暫定）；管理窗照常。
- 角色 < Lv 26：不能裝卸，拆仍可對未裝備的神格做。
- 角色 < Lv 70：所有終極鈕停用，副行含「角色等級需達 70」或列入缺少項。
- 十二神像未全亮：太歲鈕停用，寫「先點亮十二神像（n／12）」。
- 開王場途中關閉面板：未點下去就不扣；既已執行則碎片已扣、進入王場。
