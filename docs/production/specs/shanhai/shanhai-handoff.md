## 2. 暫稱與畫面文案（給本地化編輯）

### 2.1 暫稱（名詞表沒有獨立條，或僅作示意）

- **子神格、午神格**：示意圖用的神格名（十二生肖）。現況程式是 `神格・{生肖} {p}%`（`ghName`，`craft.js`）。正式稱呼若之後另定再改。不是裝備。
- 狀態摘要「單頁總覽 · 點左側對準王場」：操作句，非正式名詞。
- 「開啟：{地點名}」「一般王場 · {殿名}」「終極王場 · {殿名}」：結構句；殿名（閻羅殿、十殿閻羅、心魔・三尸、三彭、燭龍、燭九陰、蚩尤、涿鹿兵主、太歲、太歲星君）跟 main `ARENA` 走，是否收入名詞表交本地化排期。

### 2.2 已在名詞表、畫面必須用的字（不要改寫成舊分頁名）

鬼門關、心魔幻境、凶地、陰兵借道、裂口、山海寶盒、首領碎片、勾魂令、神血、神格、血霧之印。量詞：勾魂令用「張」、神血用「份」。

### 2.3 建議定稿句（可潤飾，不可改機制）

- 規則：「只花首領碎片，不用地圖卡。王場只有王，沒有小怪。倒下不退碎片。」
- 王場等級：「王場等級：Lv {n}（你打過最高的地方）」
- 不足例：「勾魂令 {n}／5，還差 {m} 張」；「還缺：{名}、{名}、角色 Lv 70」；「角色等級需達 70」；「先點亮十二神像（{n}／12）」
- 心魔減益：照 `SIN_FRAG[k].deb`（「增加 10% 技能魔力消耗」等）
- 神格管理副行：「身上只能裝 1 個 · 角色 Lv 26 起可裝 · {n}／30」
- 拆解：「拆解？」「拆成 200 靈魂。」「⚠ 不能復原」「長按拆解」「取消」
- 空收藏：「太歲、太歲星君掉的神格放在這裡」
- 滿收藏：「神格收藏滿了：換 500 靈魂」（掉落提示，不一定出現在本面板）
- main 舊句「死亡不退碎片」畫面改「倒下不退」。

## 4. 工程注意事項

- 本檔是畫面規格。改 `hud.js` `boxHTML`（拿掉 5 分頁、改單頁、頁名改地點名）、右欄對準、神格小視窗，另開實作任務，不在這個文件分支改遊戲碼。
- **開王場不要接 `holdAsk`。** 維持 `data-bx="go:{kind}"` → `openArena`（`hud.js`、`game.js`）。倒下不退已在 `openArena` 註解與死亡流程，不要加退款。
- 左欄區名對齊名詞表，不要再用「酆都／心魔劫／四凶／陰兵／弒神」。
- 碎片數量與倉庫特殊物品同一 `S.frags`。神格只在本窗與角色頁，不進倉庫。
- 長按只用於拆解：共用 `holdAsk`，`HOLD_MS = 600`。
- 名詞提示停 0.4 秒或 R3，定位防裁切，不擋點擊。
- 觸控／Deck：關閉與主鈕熱區 ≥ 44px；390 只跑自動檢查，見驗收清單。
- 驗收：照 [REVIEW-CHECKLIST.md](../../evidence/shanhai/REVIEW-CHECKLIST.md) 開雲端驗證工作階段。疊圖時把舞台裁成 1280×720，紅底編號不比。
- 實作必須套 D2 token（主檔 §3），禁止把線框灰階當成視覺規範。
