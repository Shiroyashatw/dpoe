# 修正輪 fix5：`#pinv` 補 `--panel-edge`，1280×720 修改前後對照

改動只有一行：`css/style.css` 的 `#pinv { … }` 補 `--panel-edge: var(--d2-panel-edge);`（`#a8927f`，`:root` 既有的 token；依據 M2-36 與 `specs/M2-character-1280.md` 第 19 行）。只在 `#pinv` 範圍定義，`:root` 沒動。fix4 加的後備 `var(--panel-edge, transparent)` **保留沒動**（現在用不到，值由 `#pinv` 的定義決定）。

做法：同一頁、同一份測試存檔、同一個畫面狀態（先把 `requestAnimationFrame` 停住），只把 `css/style.css` 換成修改前（`aedb27d`）再換回修改後，各截一張；換回後再截一張量雜訊。圖是「修改前｜修改後｜差異（不同的像素塗洋紅）」。
