## 範圍說明（請知悉）
- token 蓋在 `#pinv.c12`（桌機角色頁才有 `.c12`），不是 `#pinv`：直立角色頁與倉庫頁也用 `#pinv`，裁定範圍是桌機 1280 角色頁，這樣那兩頁一個像素都不變。
- 色碼沒有寫死：7 個值在 `:root` 都有同值的 `--d2-*`，全部用 `var(--d2-…)`；`tools/check.js` 沒改。
- `--btn2` 是 token，所以長按選單裡的兩顆鈕（釘到摘要、編輯釘選）底色也跟著變成 `#524c47`（圖例 B42 的 token 也列 `--btn2`）。
- 04b：大多數詞綴「主文字＋(區間) T1 ✦」本來就超過一欄 212 px（例：137＋6＋約 110），所以詳細模式常常只剩「T1 ✦」，區間看不到。這是照裁定「先縮區間」的結果；要保住區間得另外想版面。
- 每種詞綴 T1 最大值的主文字最寬 186 px（增加 36% 受招架持續時間），小於一欄 212 px，所以沒有做「詞名中間加…」；`char_check.js` 有一條斷言守這件事。
