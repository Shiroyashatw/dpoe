## 6 項衝突測試的改寫（斷言強度不變，沒有刪測試）
1. **M2-34 3a 修正 (4)**：`--rar-rare` 期望值改成定稿 `#fbe53a`／`251, 229, 58`；「光柱程式不寫死三元組」的禁止字也跟著改成新值。ΔE2000 ≤ 2、`cssv(...)` 的檢查不變。
2–4. **M2-34 3a 繪製順序（白天、燭龍閉眼、蚩尤大霧）**：辨識怪物生命條的顏色從寫死的 `#e5484d`，改成從 `PAL_CSS`（css/style.css 的 `:root`）讀 `--hp` 的實際值（現在是 `#934341`）。在 vm 裡 palette.js 同樣從 `PAL_CSS` 建出 PAL，所以 render.js 畫的 `PAL.hp` 會跟這個值相等。其他斷言（在暗層之前或之後）不變。
5. **M2-38 顏色**（規則性斷言改寫，**待 UIUX 確認**）：CSS 段原本規定「不准出現 `rgb(`」，改成「只准 `rgb(var(--*-rgb)/α)` 形式，不准寫死數字的 rgb(」。做法是先拿掉 `rgba?(var(--x-rgb)[,/] α)`，剩下的不准有 hex 或 `rgb(`。新函式還是不准有任何色碼，也還是不准定義新 token。
   - 注意：`--scrim-rgb` 是用逗號分隔的三元組（`13, 14, 17`），寫成 `rgb(var(--scrim-rgb) / 0.6)` 展開後是 `rgb(13, 14, 17 / 0.6)`，舊式逗號語法不能配斜線，CSS 會判成無效。所以 `#hask` 那兩處保留 `rgba(var(--scrim-rgb), 0.6／0.5)`，測試也接受逗號寫法。
6. **B2-CAT**（規則性斷言改寫，**待 UIUX 確認**）：原本規定「`--cat-corr` 還沒有元件用到」，改成「`--cat-corr` 只准用在判定表指定的位置（ruling.csv 原 legacy-19 那一列：`.fslot li.cw, .aff.cor` 的字色），全 css＋js 剛好 1 處」。`--cat-cal`、`--cat-cal-hi` 還是不准有元件用到；三個值不變。
