## 1. 先遷移 JS，再刪 token（grep 必須是 0）
- [ ] 每一個要刪的 token，在 PR 的 tree 上跑下面這段，結果都要是 0 筆：
  ```
  rg -n -- "var\(--TOKEN\)" css/ index.html
  rg -n "PAL(\.rgb)?\.KEY\b|cssv\('--TOKEN'\)" js/
  ```
  KEY 的換算照 palette.js：`--a-b-v1` → `PAL.aBV1`，`--a-rgb-v1` → `PAL.rgb.aV1`。
