## C. 通過標準（A／B／C／D 門檻）

**A. 疊圖**：A01–A05 每個圖例元件位置差 ≤ 2 CSS px、尺寸差 ≤ 2 px；字級與字重一致。顏色對 D2 token，ΔE ≤ 3（不要跟線框灰階比色）。超出的列一張表。

**B. 390 自動檢查**：B1–B8 全過，結束碼 0。

**C. 定案與符號**：

1. 區名只有鬼門關／心魔幻境／凶地／陰兵借道／裂口，沒有酆都／心魔劫／四凶／陰兵／弒神分頁。
2. 開王場：足夠時直接點擊，**沒有** 0.6 秒長按卡；規則或名詞提示寫明扣碎片且倒下不退。錄影：按下到進場開始 < 100 ms。
3. 拆解神格才是 600 ms 長按；裝著的不能拆。
4. 神格與碎片格沒有 `✦`、沒有當作裝備頂階的 `★`（`★` 只許出現在頂列地點星級）。

**D. 手感量測**：

- 開王場即時反應（見 C.2）。
- 拆解長按 600 ms ± 50 ms；提早放開不執行。
- 名詞提示延遲 0.4 秒 ± 50 ms，或 R3 立即出現；移開即關。
- 鍵盤 J／Esc、方向鍵、Enter（開王場不按住）與手把 Ⓐ／Ⓑ／R3 可用。

另：沒有 console 錯誤；沒有改存檔格式。結果寫在 `docs/production/evidence/shanhai/check/RESULT.md`：每項 ✅／❌、疊圖連結、未過原因。
