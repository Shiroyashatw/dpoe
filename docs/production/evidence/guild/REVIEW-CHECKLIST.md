## C. 通過標準

**A. 疊圖**：G01–G03 每個圖例元件位置差 ≤ 2 CSS px、尺寸差 ≤ 2 px；字級與字重一致。顏色對 D2 token，ΔE ≤ 3。

**B. 390 自動檢查**：B1–B7 全過。

**C. 定案與符號**：

1. 確認卡**只在會把某種材料用光時**出現；其餘直接換。
2. 皮 → 加詞石 T5＝600，與木、鐵共用 234／時；畫面無「暫定」、無＊。
3. 至臻石不能換；蛻變石、增幅石、富豪石不出現。
4. 換完寫在區頭；戰場上沒有浮動字。
5. 物品與通貨上 0 個 `★`（`★` 只許頂列地點星級），無 `✦`；規格禁用的完美程度詞 0 處。
6. 不使用「互換」。

**D. 對比**：抽量每種字／底配對 ≥ 4.5:1（規格 §6 表）。特別檢查：按鈕上次要字不是 `--tx-dim`／`--tx-off`／`--bad`。

另：沒有 console 錯誤；沒有改存檔格式。結果寫在 `docs/production/evidence/guild/check/RESULT.md`：每項 ✅／❌、疊圖連結、未過原因。
