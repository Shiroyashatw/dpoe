## 示意圖怎麼對

- 本目錄 20 張 PNG 是 4272×1520（DPR 2）。左邊舞台在 CSS (20,20) 1280×720，也就是圖上 **(40,40) 2560×1440**；右邊是圖例。

## C. 通過標準

1. A01–A17 疊圖：每個圖例元件位置差 ≤ 2 CSS px、尺寸差 ≤ 2 px；字級與字重一致；token 色差 ΔE ≤ 3。超出的列一張表（圖號、元件、差多少）。
2. 符號（全部畫面）：
   - 圖示格右上 ✦n＝頂階詞條數，用 `CH_STAR` SVG、12/700、`--tx-strong`；0 條不畫。
   - 詞列頂階詞前 ✦；破裂詞＝`affix_frac`＋「破裂」標；**物品上沒有 ★**（★ 只在地點牌）。
   - 揭曉卡、小卡、說明裡**沒有任何百分比分數**，沒有「大獎」。
   - ✦2 以上金框＋自動鎖；✦1 不鎖。
3. 揭曉：卡 216×216 正方形；20 件 2×10、104×104；全部翻開間隔 60／30 ms；✦2 演出 ①～④ 約 0.8 秒（錄影量，±20%）；跳過動畫時 ⑤ 照樣。
4. 長按：腐化、災魘（沒勾判官筆）、其餘分解含稀有都是 600 ms；聖化、破裂石、完美石、單卡分解不確認。
5. 鍵位：主檔 §8 ✅ 的都能用；⚠️ 的列出實際接法。
6. B1–B10 全過，`touch_check` 結束碼 0；`node tools/touch_check.js 1280 720` 也要 0。
7. 沒有 console 錯誤；沒有改存檔格式。
8. 結果寫在 `docs/production/evidence/forge/check/RESULT.md`：每項 ✅／❌、疊圖連結、未過原因。
