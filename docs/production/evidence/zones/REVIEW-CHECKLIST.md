## C. 通過標準（A／B／C／D 門檻）

**A. 疊圖**：A01–A04 每個圖例元件位置差 ≤ 2 CSS px、尺寸差 ≤ 2 px；字級與字重一致。顏色對 D2 token，ΔE ≤ 3（不要跟線框灰階比色）。面板寬必須是 640，不是 1248。

**B. 390 自動檢查**：B1–B7 全過，結束碼 0。

**C. 定案與符號**：

1. 未開星級以虛線畫出，玩家看得到 1★–5★ 全部；懸停未開鍵出現「升斥候營到 Lv n 才開」。
2. `★` 只用於地點星級；清單沒有 `✦`。
3. 特殊地點名稱用名詞表地點名（鬼門關／心魔幻境／凶地／陰兵借道／裂口）；裂口列名跟 `wName`。

**D. 手感量測**：

- 點已開星級立刻寫入（無確認卡）；當輪地圖詞不重抽。
- 名詞提示延遲 0.4 秒 ± 50 ms，或 R3 立即出現。
- 本面板沒有 0.6 秒長按流程。
- 鍵盤 M／Esc、方向鍵、Enter 與手把 Ⓐ／Ⓑ／R3 可用；未開星級 Ⓐ 無效。

另：沒有 console 錯誤；沒有改存檔格式。結果寫在 `docs/production/evidence/zones/check/RESULT.md`：每項 ✅／❌、疊圖連結、未過原因。
