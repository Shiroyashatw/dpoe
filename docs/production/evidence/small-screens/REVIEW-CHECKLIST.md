- 本目錄 15 張 PNG 是 4272×1520（DPR 2）。左邊舞台在 CSS (20,20) 1280×720，也就是圖上 **(40,40) 2560×1440**；右邊是圖例。

## C. 通過標準

**A. 疊圖**：每個圖例元件位置差 ≤ 2 CSS px、尺寸差 ≤ 2 px；字級與字重一致。顏色對 D2 token，ΔE ≤ 3。

**B. 390 自動檢查**：B1–B8 全過。

**C. 定案與符號**：

1. 設定滿寬三欄、快捷鍵免捲。
2. S02 是兩步確認卡，不是長按；取消是主鈕與預設焦點；危險次鈕紅框紅字。
3. 更多無追逐物品格，9 格對齊。
4. **畫面禁用詞「好胚」0 處**（含 aria-label、tooltip）；類別寫「裝備」。
5. 物品與通貨上 0 個 `★`（`★` 只許地點星級），無非頂階 `✦`；規格禁用的完美程度詞 0 處。
6. T02 背景圖槽位、62% 遮罩、安全區照規格。

**D. 對比**：抽量每種字／底配對 ≥ 4.5:1（第 1 份 §2 表）。特別檢查：`--btn2` 上沒有 `--tx-dim`／`--tx-off`／`--bad` 字；T02 壓圖字只用 `--tx-strong`／`--tx`，用最亮背景區取樣仍 ≥ 4.5:1。

**E. 手感**：B01 懸停暫停、移開續算；出現 0.4 秒內點擊不算。名詞提示 0.4 秒 ± 50 ms 或 R3 立即。

另：沒有 console 錯誤；沒有改存檔格式。結果寫在本目錄 `check/RESULT.md`：每項 ✅／❌、疊圖連結、未過原因。
