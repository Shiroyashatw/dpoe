## 3. 為什麼不到 10 件

三份通用清單裡沒標 ⚠️ 的有 142 件，大多數特色詞是「擊中／擊殺／格擋／翻滾時觸發某事」這種要新規則的，現有能力鍵組不出來。差一點就能做、缺的能力：

| --- | --- |
| 藤甲（盾） | 額外物理傷害減免：只有翠玉增益會給（`bufV('physDr')`），不是角色數值 |
| 止水（細杖） | 暴擊球上限：`chg_p` 有讀（`chgMax`），但 `stats()` 沒有這一格 |
| 紫金冠（頭） | 所有技能等級 +1：只有追憶詞 `m_lv` 放在 `o.mem.gemLv`，沒有能力鍵 |
| 百戰（腰帶） | 旗幟持續時間（榮耀獲得 `gloryP` 有） |
| 虎符（權杖） | 召喚物上限（號令冷卻 `cmdCdr` 有；只有魔像、戰狼各自的上限） |
| 火浣衣（胸） | 被點燃時增加傷害（最大火焰抗性 `maxResF` 有） |
| 捆仙繩（腰帶） | 使敵人釘身時獲得狂怒球（釘身累積 `pinP` 有） |

| 鍋蓋（盾） | 格擋時回復生命 |
| 樵夫（斧） | 對滿血敵人更多傷害：只有「必定暴擊」`fullCrit`、「先移除最大生命」`fullStrike` |
| 丈八（長矛） | 3 公尺距離門檻：`closeP` 5.3 公尺、`farP` 11.7 公尺 |

## 4. 規格沒寫、我先這樣做的地方

1. **特色詞放哪、長什麼樣**：顯示規格沒寫傳奇。特色詞接在前後綴下面（說明框是前後綴與腐化詞之間），一般字色，**不加 ★**（★ 在畫面上是破裂的記號，跟草案的 ★ 撞）、不加標題（「特色詞」不在名詞表）。鍛造台與打造揭曉卡也是接在詞綴後面。
2. **空的前後綴格**：說明框與鍛造台畫「—」，不畫「（空）」——照倉庫規格 ST-28「普通、傳奇沒有空位＝0」，傳奇不能加詞。手機比較欄、鍛造台卡頭的「前綴 n／3」照稀有裝。
3. **◈**：角色頁比較名字前面原本有「◆ 」給稀有，傳奇加「◈ 」（名詞表：◈ 只給傳奇）。其他地方照現狀（說明框標題原本就沒有記號）。掉落紀錄列用文字標籤「傳奇」（`LOGN`）；掛機條「最近一筆稀有以上」原本就會畫 ◈（`logSh` r＝3）。
4. **品質也擋**：任務列的是填、淬鍊、聖化、王印；規則寫「只能腐化」，所以磨刀石／護甲片也擋（最保守）。災魘沒動：它要先腐化，傳奇腐化後可以照舊上災魘。
5. **打造的傳奇只給同部位**：任務寫「稀有裝掉落時 2% 改成掉一件傳奇」，但 0.5.0 起戰鬥不掉裝備，裝備只從打造來；打劍出戒指不合理，所以打造只換成同部位（武器同種類）的傳奇，該部位沒有樣板就維持稀有。`dropItem`（測試與工具用）照字面，任何部位。
6. **傳奇的物品等級**：照產生它的那件稀有的物品等級，但不低於這件的最低物品等級。
7. **詞綴的 T**：照數值落在哪一階（顯示用）；比 T1 高的也記 T1，不出 T0。
8. **打造揭曉的「傳奇專屬演出」沒做**：`S/M2-item-detail-forge-reveal.md` 有 B2 傳奇單件揭曉與新音效鍵 `legend`，規格自己標「預留」，音效也還沒有；這次照稀有的演出（稀有音、亮邊）。
9. **地上光柱色 `RCOL`** 沒加傳奇色：有一條檢查固定這個陣列只有三色，裝備也不會掉在地上，就不動。

## 5. 掉落提示門檻「傳奇以上」

程式裡**沒有**這個設定（規格在 M2-40 §9、D3 T02，還沒做）。這次做的：傳奇寫進掉落紀錄時帶稀有度 3（`dropLog(…, 'uniq', null, 3)`），`logR` 回 3，所以之後做這個設定時，「傳奇以上」會直接篩得到它；現在掉落紀錄與掛機條「最近一筆稀有以上」都會出現。設定畫面本身沒做（是介面新增，不在這次範圍）。

## 6. 存檔

新增的欄位都是選擇性的（`r: 3`、`u`、`ux`），舊存檔沒有這些欄位，讀法不變，**不需要 `migrate()` 轉換**。表裡刪掉某一列時，那件傳奇照基底名顯示、特色詞照存的值照算，不會壞。
