# 詞綴池擴充草案（新單項 42 條＋複合 24 條）

來源：使用者 2026-11-27 對話（「拓寬詞綴池，補上；現在應該也沒有那種複合詞綴，一起補入」）｜狀態：草稿，不可交辦｜對 main `6bca22b`

- 現況：詞綴 39 條（`js/data.js` 的 `AFF`），每個部位 9～19 條。沒有召喚物、陷阱、異常狀態相關的詞綴；防禦只有固定值（護甲 +N），沒有「增加 X%」；沒有複合詞綴。
- 這份加兩種：**新單項詞綴**（一條給一種能力）與**複合詞綴**（一條給兩種能力，各自的數值比單項低）。稀有裝與傳奇共用同一個池。
- 新單項的 40 條用的都是遊戲裡已經有的能力（`STATN` 的鍵與寫法），只是現在沒有放進詞綴池，所以不用補底層；最後 2 條標「新」的要補能力。
- 數字全部暫定；平衡先不管。整條範圍＝T6 最低到 T1 最高，分六階的做法照現有的 `tierRange`。
- 這兩張表是給 `.claude/skills/skill-unique-design/draft_check.js` 讀的：欄位順序與寫法不要改；寫法裡的 `{}` 是數字的位置。
- 部位的寫法：武器（劍、斧、錘、細杖、長矛、弓、十字弓、匕首、爪）、法系武器（長杖、法杖、權杖、陷阱器）、盾、法器、箭袋、頭部、胸甲、手套、鞋子、腰帶、戒指、項鍊。
