# 詞綴池擴充草案（新單項 131 條＋複合 45 條）

來源：使用者 2026-11-27 對話（「拓寬詞綴池，補上；現在應該也沒有那種複合詞綴，一起補入」；第二輪：「詞綴池繼續擴充，跟 POE 兩代比我們應該還少很多詞綴數，先補進來。」）｜狀態：草稿，不可交辦｜對 main `868e5c3`

- 現況：詞綴 39 條（`js/data.js` 的 `AFF`），每個部位 8～19 條（第 5 節）。沒有召喚物、陷阱、異常狀態相關的詞綴；防禦只有固定值（護甲 +N），沒有「增加 X%」；沒有複合詞綴。
- 這份加兩種：**新單項詞綴**（一條給一種能力）與**複合詞綴**（一條給兩種能力，各自的數值比單項低）。稀有裝與傳奇共用同一個池。
- 第 1 節 131 條＝第一輪 42 條＋第二輪 89 條。來源欄：「現有能力」95 條用的是 `STATN` 已有的鍵與一模一樣的寫法，不用補底層；「新」18 條遊戲有這個概念但 `STATN` 沒有，要補能力；「加開」18 條是現有 39 條開給更多部位（見第 3 節），鍵用 `x_` 開頭只是讓工具認得，做進遊戲時改成在 `KINDS[部位].aff` 加原本的鍵。
- 數字全部暫定；平衡先不管。整條範圍＝T6 最低到 T1 最高，分六階的做法照現有的 `tierRange`。範圍參考現有 39 條的量級，沒有照抄 PoE。
- 這兩張表是給 `.claude/skills/skill-unique-design/draft_check.js` 讀的：欄位順序與寫法不要改；寫法裡的 `{}` 是數字的位置。其他表的第一欄不要放英數鍵（工具會當成詞綴讀）。
- 部位的寫法：武器（劍、斧、錘、細杖、長矛、弓、十字弓、匕首、爪）、法系武器（長杖、法杖、權杖、陷阱器）、盾、法器、箭袋、頭部、胸甲、手套、鞋子、腰帶、戒指、項鍊。
