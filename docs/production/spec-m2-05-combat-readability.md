## M2-05.2 傷害數字疊法

目標：同一時間看得懂「打了多少、有沒有暴擊、我自己挨了多少」，而不是一團數字。

| 編號 | 規格 |
| --- | --- |
| M2-05.2a 合併 | 同一隻怪、同一種顏色（物理／火／冰／電／混沌）在 0.3 秒內的一般擊中合併成一個數字：數字留在原地往上加（例如 21 → 47），每加一次放大 1.15 倍 0.08 秒再回原大小。合併中的數字壽命從最後一次加上去起算 0.9 秒。 |
| M2-05.2b 暴擊不合併 | 暴擊永遠自己一個數字，字級維持 24（現況），排在合併數字的上一格。豪賭大獎同理（30）。 |
| M2-05.2c 挨打不合併、位置固定 | 玩家受到的傷害（hurt，紅 #ff5a5a）只出現在玩家頭上，不跟任何輸出的數字混在一起；0.3 秒內的也合併成一個。 |
| M2-05.2d 排隊 | 同一隻怪頭上最多 3 條：由下往上是 一般合併數字 → 暴擊 → 第二個暴擊。每條間距 14 px（螢幕）。新的一條出現時，舊的往上推，不重疊。 |
| M2-05.2e 全畫面上限 | 390×844 與 375×667 同時最多 8 個數字；1280×720 最多 14 個。超過時依優先序丟掉最低的：挨打 > 暴擊／大獎 > 一般擊中 > 金幣 > 持續傷害 > 閃避／格擋字。 |
| M2-05.2f 持續傷害 | 持續傷害（dot，12 px 淡紅 #c9a3a3）不再每跳一次就出一個數字；改成每 1 秒把這 1 秒的持續傷害合成一個數字，12 px 改 13 px。直立時如果同一隻怪已經有 3 條，持續傷害直接不畫。 |
| M2-05.2g 金幣 | 「+n 金」不再跟傷害數字一起跳在怪身上；改成跳在撿起的位置（玩家頭上偏右 16 px），0.5 秒內的合併。直立要不要飄金幣已移交 M2-23（已決定 2026-11-17），本頁不定；M2-23 交件前，直立先只更新頂端資訊列的數字、不畫世界字。金幣字不受 M2-05.5 設定影響（它不是傷害數字）。 |
| M2-05.2h 螢幕字級下限 | 世界字的字級要換算成螢幕大小：一般擊中在螢幕上 ≥13 px、暴擊 ≥18 px、挨打 ≥14 px。縮放變小時（M2-04 之後 ZOOM 依視窗算）用除以 ZOOM 補回來。黑色描邊維持 4 px 世界單位，螢幕上至少 2 px。 |
| M2-05.2i 減少動態 | prefers-reduced-motion 時不放大彈跳、不往上飄，原地淡出 0.6 秒。 |

## 驗收清單（給 M2-06）

- **1. 地面不寫字**：任何地面效果上都沒有文字；怪物方有紅虛線＋中央圖示；站上去時狀態列出現名字。390×844、375×667、1280×720 各截一張。
