# 傳奇物品草案（112 件）

來源：使用者 2026-11-27 對話（「先設計 100 多件傳奇物品，目前遊戲沒有半件傳奇」）｜狀態：草稿，不可交辦｜對 main `bd796d1`（v0.5.6）

- 現況：稀有度只有普通、魔法、稀有。名詞表 v0.6.21 已收「傳奇」這個稀有度名與 ◈ 記號，但程式還沒有，企劃書 5.1 還寫「不放傳奇、套裝」。追逐物品目前只有 4 個王印。
- 範圍：112 件。武器 39（13 類各 3，魔符隱藏不做）、副手 10、防具 32、飾品 19、十二生肖 12。
- 數字全部暫定；平衡先不管。名詞表還沒改，圖示還沒有。
- 標 ⚠️ 的是我判斷要補新規則的；沒標的是用現有名詞或現有能力組的。兩種都還沒有逐條對過程式。

## 0. 設計規則

1. **每件一條改規則的詞**。傳奇不是數字比較大的稀有裝，是「戴上去打法就變了」。每件 1～2 條普通詞（給基本強度）＋ 1 條特色詞；有些特色詞帶代價。
2. **刷的爽**：一批是越殺越強、擊殺連鎖、自動清場；一批是掛機有感的（復活、續航、撿更多）。
3. **用現有名詞**。這些名詞遊戲裡已經有定義，但沒有裝備或天賦會給（查過能力表），這批替它們找到家：終極、流順之風、翠玉、風暴湧流、滿溢聖杯、靈巧、迷蹤、易攻目標、屠戮打擊、壓碎、碎甲、破碎護甲、擴散傷害、封印、溢出、幸運、奉獻地面、荊棘、偏斜、殺戮、執政官。
4. **名字跟世界觀走**：十二生肖神、酆都（牛頭馬面、黑白無常、閻羅）、心魔劫（七情、三尸）、四凶與燭龍、陰兵借道（刑天、風伯、雨師、蚩尤）、太歲，加上神話與典故。
5. **來源寫的是建議**：哪個王掉哪一件，讓玩家有目標可以刷。沒寫來源的是全域掉落。
6. 基底用遊戲裡現有的 303 個基底名。
