**查詢日期：2026-11-06**。只研究，未下載任何音檔，未改程式。

> 方法說明：官方頁面能抓到的（Freesound FAQ、Pixabay 條款、Sonniss 授權、Incompetech、Kenney、FMA 授權指南）標「官方確認」；OpenGameArt、itch.io、Mixkit、Zapsplat 因站方擋抓取或授權全文沒抓到，標「搜尋摘要／待補」，上線前一定要逐檔開頁面核對。這不是法律意見，⚠️ 為建議律師或自行再確認處。

## 0. 授權分類總覽

| 類別 | 商用 | 署名 | 放進公開 GitHub repo 並隨遊戲散布 | 備註 |
| --- | --- | --- | --- | --- |
| **CC0** | 可 | 不用（建議留紀錄） | 沒問題 | 最安全，優先選 |
| **CC BY 3.0/4.0** | 可 | **要**（作者、標題、連結、授權、有無修改） | 可，需附署名與授權連結 | 不可加 DRM（OGA 提醒）。遊戲內「製作名單」畫面＋repo 都放署名 |
| **CC BY-SA** | 可 | 要 | ⚠️ **風險最高**：改編後的作品須以同授權散布。音檔本身 SA 沒問題，但「遊戲＋音檔」算不算合成作品有爭議；剪輯、混音後的音檔必為 SA。建議不用 | 與「公開 repo + 日後商業化」衝突 |
| **CC BY-NC（含 ND）** | **不可** | 要 | 與商業化衝突，**一律排除** | Freesound、FMA 都有，篩選時要排除 |
| **GPL（OGA 的部分音檔）** | 傳染性 | 要 | 衝突，排除 | 若同作品多重授權，選 CC0／CC BY 那個 |
| **自訂授權（Pixabay、Mixkit、Sonniss、Zapsplat 等）** | 通常可 | 看站 | ⚠️ 共通地雷：**禁止「單獨散布原始檔」**。公開 repo 放著原檔，等於任何人可抓走，可能算違規 | 只有 Sonniss／Pixabay／Zapsplat 明文有此條 |

**與「公開 repo 內含音檔」衝突的：**
1. CC BY-SA、GPL、所有 NC／ND。
2. 自訂授權裡的「禁止單獨散布」：Sonniss（明文禁止以音效形式提供，無論修改與否）、Pixabay（Standalone 不得散布；剪裁、改色、縮放仍算 Standalone）、Zapsplat（禁止單檔散布）。把這些檔放進公開 GitHub repo，技術上就是公開提供原檔下載。⚠️ 是否構成違規需律師判斷；保守做法是不放進公開 repo（見第 5 節）。
3. CC BY 本身不衝突，但要隨附署名。

## 4. 授權風險點總結

1. **公開 repo 內含音檔**是最大衝突：CC0 與 CC BY 沒事；Sonniss、Pixabay、Zapsplat 這類「禁止單獨散布」的自訂授權，repo 一公開就等於提供原檔下載。⚠️ 需律師判斷；保守做法是只放 CC0／CC BY 的檔進 repo。
2. **站內逐件授權**：OGA、Freesound、FMA、itch.io 同站不同授權，包含 NC 與 SA，混用容易誤選。要逐檔記錄。
3. **「免費商用」非正式授權**（itch.io 常見）：沒有授權條款文字，日後商業化無法舉證。⚠️
4. **署名義務累積**：CC BY 一多，製作名單會很長；需要名單頁。
5. **AI 生成內容**：Pixabay 允許上傳 AI 生成並要求標示；部分 itch.io 作者用 AI。AI 生成音樂的著作權與授權歸屬有不確定性 ⚠️。
6. **Content ID**：遊戲內播放不會被偵測，但日後拍影片、實況、預告片時，Kevin MacLeod 這類被廣泛使用的曲目有被誤認的先例。官方有申訴流程。
7. **OGA／itch.io 上傳者可能不是原作者**（盜用他人作品上傳）。⚠️ 難完全排除，只能避開可疑檔案並留存下載頁截圖。
8. **站方條款會變**：Pixabay 條款 2026-10-20 才更新、Sonniss 2026-08-27 更新授權 v2.0。下載當日要存授權頁。

## 5. 推薦方案

### 音樂
- **BGM（藏身處、地城、冰原、岩漿、毒沼）：Incompetech（CC BY 4.0）為主，OpenGameArt 的 CC0 氛圍曲補強。**Kevin MacLeod 曲目多、分類好找，授權單純（只要署名）。
- **東方風／王戰／開場動畫：OpenGameArt CC0 東方曲（asianoriental2、Jaoan 等）＋Kevin MacLeod 史詩曲**；若品質不夠，再考慮付費東方包（但不放 repo）。
- 署名文字（Incompetech）：
  ```
  "曲名" Kevin MacLeod (incompetech.com)
  Licensed under Creative Commons: By Attribution 4.0 License
  https://creativecommons.org/licenses/by/4.0/
  ```
  OGA 範本：`"作品名" by 作者 licensed CC-BY 3.0／4.0，連結`。

### 環境音
- **OpenGameArt 的 CC0 洞窟環境（Dark Cavern Ambient、Dungeon Ambience）、Freesound 篩 CC0。**避開 NC。

### 戰鬥音效
- **Kenney Impact Sounds＋RPG Audio（CC0）為底，Freesound CC0 補血肉、火焰、冰裂等特殊音。**不夠再用 Sonniss，但音檔**不放公開 repo**。

### UI
- **Kenney Interface Sounds／UI Audio（CC0）**，或 jsfxr 自產（符合像素風）。

### 格式與大小（網頁遊戲）
- **BGM：OGG Vorbis（q3～q4）或 Opus**，單曲約 1～2 MB；Safari 的 OGG 支援較新，**備援同時放 MP3**（`audio.canPlayType` 判斷，或只輸出 MP3 128 kbps 以求簡單）。
- **音效：短檔，OGG／MP3 皆可，單檔小於 50 KB；多個音效可合成 audio sprite。**
- **循環點：MP3 因編碼延遲會有縫隙**；要無縫循環用 OGG／Opus，或自己剪好循環點後用 Web Audio `AudioBufferSourceNode` 的 `loopStart`／`loopEnd`。
- **預算：首次載入不超過 3～5 MB 音訊；BGM 按場景延遲載入**；GitHub Pages 單檔上限 100 MB、站點建議 1 GB，足夠。
- 目前音效是 `js/audio.js` 用 Web Audio 即時合成：可保留合成做 UI 與命中音（零授權風險），只把 BGM 與環境音換成檔案。

### 授權紀錄保存（`dpoe/` 內）
1. 新增 `dpoe/audio/CREDITS.md`（或 `dpoe/docs/音訊授權紀錄.md`）：每個音檔一列：檔名、原標題、作者、來源網址、授權名稱＋版本、下載日期、是否修改、署名文字。
2. 每個來源放一份授權文字檔：`dpoe/audio/licenses/CC-BY-4.0.txt` 等，以及下載當日的授權頁截圖／PDF（Kevin MacLeod 官方也建議保留）。
3. 遊戲內的「製作名單」頁讀同一份資料，確保署名隨遊戲出現。
4. 檔名帶來源前綴，例如 `bgm_incompetech_曲名.ogg`、`sfx_kenney_impact01.ogg`，便於稽核。
5. 不放 repo 的素材（Sonniss、付費包）另存私人位置，repo 只放轉檔後、已與其他聲音混合的成品；⚠️ 這樣是否符合「不得單獨散布」仍建議律師看過。

## 6. 需要律師或再確認的 ⚠️ 清單
- Sonniss、Pixabay、Zapsplat：音檔放公開 repo 並隨網頁散布是否算「單獨散布」。
- Mixkit：授權全文沒抓到，無法判斷。
- SoundImage.org：官方 /attribution-info/ 全文沒抓到，只有作者論壇說明。
