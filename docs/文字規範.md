# 遊戲內文字規範（2026-11-11，照 PoE2 台服）

**權威**：遊戲裡所有給玩家看的文字（技能、輔助、光環、覺醒、名詞、能力名稱、昇華、通貨、地圖詞、面板提示）都照這份寫。參考來源是 PoE2 台服的技能寶石與關鍵字（poe2db.tw/tw），重點都整理在這裡。

## 1. 總原則

- **照程式寫，不照想像寫**：每一條都要對過程式的實際效果；文字和程式對不上，一律改文字（使用者 2026-11-11）。
- **不解釋原因、不重複名詞定義**：名詞點了就有說明（`TERMS`），正文只寫這一招／這一點特別的地方。
- **預設規則不寫**：冰冷擊中會累積冰凍、物理與近戰累積更多沉重暈眩、詛咒每隻怪 1 個……這些寫在名詞裡，技能不寫。只有「比預設多」或「不照預設」才寫，例如「100%更多冰凍累積」「無法造成暈眩累積」。
- **沒有贅字**：不寫「會」「的時候」「可以」「這一招」「（移動變慢）」這種補充；不寫括號裡的解釋。

## 2. 用語（台服）

| 意思 | 寫法 | 例 |
| --- | --- | --- |
| increased／reduced（同池相加） | 動詞在前：增加 X%…／減少 X%… | 增加 15% 攻擊速度 |
| more／less（相乘） | 數字在前：X%更多…／X%更少… | 造成 20%更少傷害、100%更多冰凍累積 |
| 加值 | …+X | 投射物 +2、最大生命 +50 |
| 附加 | 附加 A 至 B 火焰傷害 | |
| 額外 | 獲得等同於 X% 傷害的額外冰冷傷害 | |
| 轉換 | 將 X% 的物理傷害轉換為冰冷傷害 | |
| 異常幅度 | 施加的冰緩具有 X%更多幅度 | |
| 條件 | 對受冰緩的敵人造成…、擊中時…、被擊中時…、冰凍敵人時… | |
| 否定 | 無法連鎖、無法造成暈眩累積、不能被閃避 | |
| 機會消耗 | 情況許可時，消耗一道冰冷灌注，… | |
| 上限 | X 上限為 N | 殭屍上限為 10 |
| 長度、範圍 | 範圍為 X 公尺（30 像素＝1 公尺，`METER`） | 爆炸範圍為 2.4 公尺 |
| 時間 | 持續時間為 X 秒、冷卻時間為 X 秒、施放時間為 X 秒 | |

狀態形容詞：受冰緩、被詛咒、遭沉重暈眩、可冰凍、可暈眩、受禁錮、帶有印記。

名詞照台服：曝曬（不是曝露）、暴擊球／狂怒球／耐力球、撲殺、目眩、釘身、觸電（Electrocute）、感電（Shock）、粉碎、近期（過去 4 秒）。

## 3. 技能、光環、覺醒（主動技能）

兩層：

1. **說明**（`d`）：一到三句話，講這招做了什麼、它的特色（連段、消耗灌注、觸發條件）。**幾乎不放數字**。開頭用動詞：「發射…」「猛擊地面…」「對一個目標施加印記…」「啟動時，…」。
2. **詳細**（展開才看到）：一行一個數字或一條規則。
   - 程式算得出來的自動產生（`skpanel.js`）：造成多少傷害、施放／攻擊時間、魔力消耗、冷卻時間、範圍、持續時間、投射物數、暴擊率、保留精魂。
   - 程式算不出來的特殊規則手寫在技能資料的 `x`（字串陣列），例如「穿透所有目標」「無法連鎖」「100%更多冰凍累積」「情況許可時，消耗一道火焰灌注，留下燃燒地面」。數字會隨等級變的不要手寫。

## 4. 輔助

- 說明：「輔助 X 技能，使其…」或「輔助任何會擊中敵人的技能，使其…」，一句話，代價也寫在這句。
- 詳細：「被輔助的技能…」開頭，一行一條。

## 5. 名詞（`TERMS`）

照 PoE2 關鍵字：第一句定義「X 是…的異常狀態／減益效果」，接著寫怎麼產生、預設數字（持續幾秒、幾%）。一個名詞只講自己，不舉技能當例子。

## 6. 昇華、天賦大點

一行一條、宣告句：「你的擊中為粉碎重擊」「X 也會貢獻至 Y」「…，改為…」「無視…」。好處在前，代價另起一行「X%更少…」。

## 7. 面板提示

只寫玩家下一步要知道的事，一句話；不重述面板上已經看得到的數字。
