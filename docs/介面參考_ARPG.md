### 1.2 技能頁

版面（巴哈 2022～2023 的圖，橫向）：

| 區塊 | 內容 |
| --- | --- |
| 左欄 | 上 5 顆主動技能（鍵位 2、3、4、…、E），下 4 顆被動技能；選中的有亮邊 |
| 中間 | 一個大圓環。**正中央＝選中的技能；環上 5 個位置＝輔助技能**（每顆名字標在旁邊） |
| 圓環下方 | 唯一的大數字：「每秒傷害 863143」 |
| 右上 | 能量「345/350」（用來開輔助格） |
| 點一顆輔助 | 旁邊彈出一張小卡：圓形圖示＋等級徽章（16，+6）、名字、裝備需求 Lv、標籤、魔力消耗倍率 110%、「簡略」開關、說明（數字上色，−30% 紅、+33% 綠）、底部三顆按鈕：清單、卸下、**黃色「更換」** |
| 能量分配頁 | 另一頁：每個技能一列、一條帶刻度的橫軸，標 10／15／50／100 等門檻 |

- **主數字有，差多少沒有**：換輔助時小卡只寫這顆輔助的效果，沒看到「換上去每秒傷害 ＋／−多少」（圖）。
- 升級按鈕在哪：**沒查到**（圖上沒有；輔助圖示的「16 (+6)」是等級加成）。
- 換一顆輔助要幾下：點輔助（1）→「更換」（2）→選新的（3）→（可能要確認，沒看到那一步，二手）≥3 下，從戰鬥畫面再 +1（打開選單）。
- 數量規則（二手）：每個主動／被動技能最多 5 個輔助；除第 1 格外，開格要花「能量」，能量主要來自換高物品等級的裝備。[巴哈](https://forum.gamer.com.tw/C.php?bsn=74756&snA=3060)、[遊民星空](https://www.gamersky.com/handbooksy/202305/1598579.shtml)（搜尋摘要）
- 玩家抱怨（Steam，2022-10，二手）：技能頁不能直接從商店裝、輔助清單不篩選能用的、標籤清單沒捲軸、技能圖示不顯示等級。[討論串](https://steamcommunity.com/app/1974050/discussions/0/5254037276307385144/)

### 1.4 倉庫

- 只在城鎮可用。一個倉庫分頁 35 格，一開始 1 個，最多 20 個，每個 400 碎裂原晶（二手，Maxroll 摘要）。
- 跟背包的差別：倉庫是另外的頁，不是同一畫面的第二區塊（二手）。
- 搜尋、排序、批量移動：**沒查到**。

### 1.5 物品說明框

兩種長相，看載體不同：

**A. 桌機預設說明框**（圖，Bilibili 2026；欄位由上到下）

| 順序 | 欄位 |
| --- | --- |
| 1 | 名字（稀有度色），右上物品圖示 |
| 2 | 等級（物品等級）／類型（部位）／需求等級 |
| 3 | 能量＋一條黃色橫條 |
| 4 | 狀態標籤（已侵蝕等，紫字）；武器另有「每秒物理傷害」一行，0 時前面是紅色驚嘆號 |
| 5 | 基底詞（例：146 最大護盾） |
| 6 | 一條分隔線，下面是詞綴，**每行前面一顆菱形（金色＝一般、紅色＝特殊／珍品）**；**沒有階級標示** |
| 7 | 傳奇裝的故事文字 |
| 8 | 最下面一行小字：部位標籤（「副」）＋「已裝備」 |

**B. 手機／製作用的卡片**（圖，Bilibili）：頂部圖示＋名字＋物品等級＋部位；下面「前綴 (3/3)」三列、「後綴 (3/3)」三列；**每列前面一顆階級晶片（T1／T2／T4／T7），後面一顆勾選圓**；卡片底部中間有「詞綴列表」按鈕。→ 階級只在這個卡片出現，桌機說明框沒有（呼應 `火炬之光無限參考.md` 第 1 節「點詳細才看 T」的說法，這次由圖證實）。

**比較**（圖，gamerhour 2022）：選到背包裡一件，卡片只在左邊出現一張：名字、需求等級、類型、大字「DPS 9」，下面一行「傷害 +999%（綠）｜生存 0%」，最下一排：鎖頭、清單、**黃色「Gear」（穿上）**。→ 比較是**一行摘要**（傷害％、生存％），不是逐條詞綴對照。
抱怨（Steam，二手）：2022 要點三下才看到比較；2023-01 說比較視窗太大；雙持時比較提示擋住背包。[討論串 1](https://steamcommunity.com/app/1974050/discussions/0/5562542086328405276/)、[討論串 2](https://steamcommunity.com/app/1974050/discussions/0/5254037276307385144/)

手機點一下 vs 桌機懸停：手機點選出現卡片；桌機懸停的長相**沒查到圖**（2023-02 預告加懸停浮動說明，二手：[開發日誌 #27](https://www.taptap.io/post/4668326)）。

### 1.6 換裝

- 步驟（圖＋文字，gamerhour）：右上背包圖示（1）→ 點背包裡的裝備（2，卡片出現）→ 黃色按鈕穿上（3）。從戰鬥畫面算 **3 下**，已在背包就 2 下。
- 「可能升級」標記：背包格子上**沒看到**（圖是 2022 的初期畫面）；現版**沒查到**。比較只靠卡片上的傷害％／生存％。

圖（Bilibili 2026）：做裝是**獨立面板**，左右兩半。

| 區塊 | 內容 |

### 1.10 該學／不該學

**該學**

1. 技能頁：中間一個主技能、環上掛輔助、圓環下方**一個**大數字（每秒傷害）；點輔助彈小卡、小卡底部一顆黃色「更換」。
2. 做裝面板：一個畫面一顆黃色大按鈕，材料與成功率貼在它正上方；詞綴前綴 3＋後綴 3 一列一列，每列自帶階級晶片與鎖定勾。
3. 說明框先給名字、等級、能量條、基底、詞綴；階級晶片只在卡片／製作時出現，一般說明框乾淨。
4. 比較收成一行「傷害 ±%｜生存 ±%」，不用逐條對照（缺點：看不到哪條詞綴變了）。
5. DPS 視窗是疊在戰場上的小視窗（有分頁、✕、按鈕），不佔滿畫面。
6. 角色面板貼在右側 1/3，戰場留在左邊。

**不該學**

1. 把手機介面原封搬上桌機：不能懸停、字太大、視窗全螢幕（2022 全部被罵）。
2. 比較要點三下才看得到；雙持時比較提示擋住背包。
3. 滑桿縮放只是把版面往中間擠，不是重排。
4. 背包分頁各自擴充、要買：資訊少、價格感很重。
5. 技能頁的輔助清單不篩選能用的，也不顯示「換上去變多少」。

| 底部主要按鈕 | **一顆紅色「EQUIP」**；按下後右下的鍵位亮起，按鈕變「CANCEL」；已裝備的想移動，改按「Switch Slot」 |

- **沒有輔助技能這一層**：技能自己有 Rank，Rank 隨角色等級自動升，不用按升級鈕（game8 文字）；傳奇寶石（鑲在裝備上）與符咒改變技能（二手）。使用者問的「技能符文」：**沒查到**畫面（遊戲裡的 Runes 另有一頁，我沒找到掛在技能上的圖）。
- **主數字**：沒有。說明只列技能本身的傷害數字，沒有「換上去 DPS 變多少」。
- **換一個技能**（最常做的事）：☰（1）→ 技能（2）→ 點清單裡的技能（3）→ EQUIP（4）→ 點鍵位（5）＝**5 下**（圖＋文字：[game8](https://game8.co/games/Diablo-Immortal/archives/377095)、[gamertweak](https://gamertweak.com/equip-change-skills-diablo-immortal)）。
- **換一顆寶石**（最接近我們的「換輔助」）：背包（1）→ 點裝備（2）→ 說明框底部「SOCKET GEMS」（3）→ 寶石彈窗點一顆（4）→ SELECT（5）。彈窗：左上目前這顆，右邊寫選中寶石的效果（「共鳴 +30」「戰力 +12」），底部一顆紅色 SELECT；**沒看到換上去的差多少**（圖）。

### 2.4 倉庫

- 城鎮裡的箱子（小地圖與世界上有箱子圖示；圖：gamepressure 的城鎮截圖黃框圈出）。
- 48 格，**裝備佔 2 格**（所以只放裝備是 24 件）；加分頁：第一個 2,000 白金（永久），第二個要有效的 Boon of Plenty，過期後只能取不能放（二手，playerassist；它的 8 張圖我載不出來，所以沒看到實際畫面）。
- 搬法：雙擊（點兩下）直接搬，或說明框上的「Store」按鈕（二手）。
- 搜尋、排序：**沒查到**。倉庫是否角色共用：兩個來源互相矛盾（gamepressure 2022 說共用、另一篇說沒有），不採用。
- **戰備庫（Armory）**（圖，gamepressure）：左列「RIFT／EXPLOR…／LOADOUT 3、4、5」，中間是這組配置的裝備格，右邊技能列與 Paragon，底部「OVERWRITE」「ACTIVE」。放倉庫的裝備切換配置時自動換上。

### 2.5 物品說明框

**版面（圖，gamerguides，PC）：卡片貼在畫面左半，格子在右半不被擋。**

| 順序 | 欄位 |
| --- | --- |
| 0 | 頂端小標籤「EQUIPPED」（只在已裝備那張） |
| 1 | 名字（大寫） |
| 2 | 圖示（左）＋**一個大數字：Damage／Life**，下面 Score 636(716) |
| 3 | ATTRIBUTES：藍字，每行一條 |
| 4 | MAGIC：效果句 |
| 5 | SOCKETS：「Empty」 |
| 6 | UPGRADES：+4 Fortitude |
| 7 | 底部：左邊小箭頭（展開）、右邊**一顆紅色大按鈕：EQUIP（已裝備那張沒有、鑲寶石時是 SOCKET GEMS）** |

- **詞綴不標階級**：沒有 T 或星級的標示；用區塊標題分（ATTRIBUTES／MAGIC）（圖）。
- **比較**（圖）：選到背包的一件，**兩張卡並排**：左＝你現在穿的（EQUIPPED），右＝選中的。右卡的主數字右邊有**綠色向上箭頭**（Damage 93▲、Score 803▲），ATTRIBUTES 標題旁有**紅色向下箭頭**（屬性比較低）。箭頭只標方向，不寫差多少。括號 636(716) 的意思：**沒查到**。
- 不擋清單：卡片佔中間，右邊格子全在，左邊裝備欄也還露出（圖）。
- 卡片較長時會裁掉下面（UPGRADES 被切）（圖，要捲）。
- 手機點一下：選到就出現這種卡（技能頁與背包都是「選＋底部一顆按鈕」，圖）；桌機懸停：2023-08 起有（二手）。

### 2.6 換裝

- 從戰鬥畫面：右欄背包（1）→ 點背包格子（2，兩張卡出現）→ EQUIP（3）＝**3 下**；已在背包就 2 下。
- **可能升級標記**（圖）：背包格子**左上角有綠色向上箭頭**；已裝備的那格有紅點（意義沒查到）。→ 不用開卡片就看得到哪些值得換。
- 換上更好的裝備時，遊戲問要不要把升級等級與寶石轉過去（二手，搜尋摘要）。
- 掉到背包的新裝有沒有自動換：沒查到。

### 2.7 做裝入口

- 鐵匠（城鎮 NPC）是**獨立面板**，不掛在裝備上（圖，game8）：左側直排選單 SALVAGE／UPGRADE／RANK TRANSFER；右側是裝備清單，點一件加進分解／升級；下面彈出所需材料。清單就在右邊，可以直接點下一件。
- 寶石、傳奇鑲嵌：**掛在裝備說明框上**（SOCKET GEMS，圖），不用跑去 NPC。
- 精華轉移是另一個 NPC 面板（圖：EXTRACT／INHERIT，每列一個效果＋一顆 EXTRACT）。
- 所以它是**兩種入口並存**：常用的（鑲寶石）掛在裝備上，重的（分解、升級、轉移）去 NPC。

### 2.8 掉寶標籤

- 傳奇掉落：**一道金色／橘色光柱**，手機截圖裡直立一條很顯眼的橘線（圖，gamerguides）；Blizzard 稱光柱讓傳奇「不會認錯」（二手：[Gamer Guides](https://www.gamerguides.com/diablo-immortal/guide/gameplay/equipment)）。
- 稀有度顏色：白／藍／黃／金（傳奇，文字）。
- 自動撿取：設定裡可勾「普通、魔法、稀有」（二手，Fextralife、game8）；傳奇不自動撿、要手動（二手，playerassist）；手機右下一顆手形按鈕：手動撿＋互動共用（二手，Fextralife）。
- 地上標籤的字級、重疊處理、過濾規則：**沒查到**（試過 gamerguides、Fextralife、game8 設定頁；沒有地上標籤的清晰截圖）。

### 2.10 該學／不該學

**該學**

1. **比較＝兩張卡並排**：左＝現在穿的、右＝選中的；主數字旁綠▲紅▼，卡片貼左半、格子在右半不被擋。
2. **格子左上角的綠▲**：不開說明框就知道哪些可能是升級。
3. 說明框只有**一個大數字**（Damage 或 Life），其他按區塊標題分組，詞綴不標階級。
4. 說明框底部**只有一顆主要按鈕**（EQUIP；已鑲嵌則變 SOCKET GEMS）。
5. 技能頁：左清單＋右詳情＋底部一顆 EQUIP＋右下複製的鍵位，選了再點哪格放；有「CANCEL」。
6. 戰備庫：一組配置＝一列，OVERWRITE／ACTIVE 兩顆按鈕。

**不該學**

1. 選單面板沿用手機比例到桌機（官方自承「偏大」）；懸停、右鍵拖很久才補。
2. 換技能要 5 下；選寶石的彈窗不寫換上去差多少。
3. Score 636(716) 括號不說明（我也沒查到意思）。
4. 倉庫與擴充分頁綁付費（第二個分頁要 Boon of Plenty，過期不能放）。
5. 傳奇要先鑑定才能裝，多一步。

## 第三章　兩款共同點

| 畫面 | 兩款都這樣 |
| --- | --- |
| 主畫面 | 戰鬥一直在；入口集中在**右上一小排圖示**，其他進選單；面板是疊在戰場上的視窗，不另開一個畫面 |
| 技能頁 | 一個選中的主技能占中央／右邊詳情；底部或旁邊**一顆有顏色的主要按鈕**（TLI 黃「更換」、DI 紅「EQUIP」） |
| 數字 | 一個大數字（TLI 每秒傷害、DI 說明框的 Damage／Life）；**都沒有寫「換上去差多少」**（TLI 只在說明框比較摘要；DI 用箭頭） |
| 背包 | 格子；**分類分頁**（TLI 4 個、DI 5 個圖示）；鎖定掛在說明框；批量賣出都不顯眼（沒查到） |
| 說明框 | 貼在畫面一側、不蓋整個格子；一個主數字；底部一顆主要按鈕（TLI「Gear」、DI「EQUIP」） |
| 換裝 | 點格子→按鈕＝2 下（從戰鬥 3 下） |
| 做裝 | 掛在**獨立面板**（TLI 做裝台、DI 鐵匠）；一件東西在畫面中、一顆大按鈕；DI 的鑲寶石例外，掛在說明框上 |
| 掉寶 | 傳奇有**光柱**（都是橘／金色）；稀有度分色；有自動撿取過濾 |
| 平台 | 都是手機優先，桌機初期被罵「手機介面」（沒懸停、字太大、視窗全螢幕）；之後一點一點補；官方大改（TLI 2024 PC UI、2026 圖示）反應我沒查到 |

### 最值得我們學的 3 件

1. **比較直接寫在說明框，而且跟著主數字**：DI 兩張卡並排＋綠▲紅▼，加上**格子左上角的綠▲**；TLI 一行「傷害 ±%｜生存 ±%」。我們要選一個：建議照 DI 的位置（左邊現在穿的、右邊選中的、清單不被擋），但把箭頭後面補上「差多少」。這兩款都沒補（DI 箭頭沒數字、TLI 只有％），正是我們 `DESIGN.md` 第 2 節「變強的語言」可以贏的地方。
2. **一個面板一個顏色鮮明的主按鈕，代價貼在正上方**：TLI 做裝台（「消耗」＋「成功率 100%」＋黃色「打造」）、DI 說明框（EQUIP／SOCKET GEMS 隨狀況換字）。跟 `DESIGN.md` 第 1 節「一個主要按鈕固定在底部」一致。
3. **技能頁用一個「中央主技能＋環狀輔助＋一個大數字」，點輔助出小卡＋「更換」**（TLI）。我們的技能面板三層（總覽 → 這一招 → 挑選）比它多一層，但它的第二層（圈圈＋一個每秒傷害）很值得照；唯一要補的是它缺的「換上去變多少」。
