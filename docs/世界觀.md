# dungeonPOE 世界觀

2026-11-06 定案。故事圍繞一個問題：**神為什麼不再庇護我們？** 每個機制揭開一層，真相一層比一層糟。文字要淺顯：不用時辰、不用艱深詞。

## 3. 各章的預定方向（可改）

| 章節 | 玩家以為 | 真相 |
| --- | --- | --- |
| 弒神（狩獵之血） | 生肖神背叛了人類 | 血霧是神流的血。牠們在流血，血霧循著你身上的神血追來 |
| 心魔劫（原七宗罪） | 外來的妖魔打傷了神 | 七情靠人心滋長；三尸住在人身體裡，把人心的罪送上天，弄髒了獻給神的供奉。傷神的是人自己 |
| 陰兵借道（原亡靈軍團） | 打倒墮落神就能救世 | 十二神鎮守的是大陸底下的冥門。神倒下一隻，門就開一道，而動手的是你。第一批從門裡回來的，是當年戰死涿鹿的兵主蚩尤和他的軍團 |
| 酆都（原冥府） | 酆都是最後的敵人 | 地層就是冥府的上層。你本來已經死了，是十二神用最後的血把你送回來 |

現有機制的理由：

- **死亡**：你本來就是死者，所以死了還會回來。
- **狩獵進度條**：血霧跟著你身上的神血聚集，所以刷圖會累積。
- **5★ 變多**：血霧讓怪物更兇殘。
- **藏身處的十二神像**：打倒一隻生肖王就點亮一尊。玩家以為在拯救世界，其實每點亮一尊就開了一道冥門。

- **四凶**（饕餮、窮奇、檮杌、混沌，終局燭龍）：不在上面的真相表裡，跟其他四條的關係之後再寫。
- **最終章「天空的裂縫」**：五條線上面的那一層，之後再設計。各線的終局王（例：太歲在天上）只暗示跟天裂有關，不解開「誰劈開天空」。

## 4. 人物

- **撿骨師**：帶主線與序章。在地層出口替沒回來的遠征軍撿骨，撿了三年。
- **天星商會掌櫃**：藏身處的商人，天星商會的人。第一次見面只說生意照做、貨準時到，不解釋怎麼送來的；之後開店時換著說一句（`js/npc.js` 的 `TRADER_SAY`）。神秘管道是伏筆，留白：貨怎麼來、商會知道多少。

## 6. 勢力

天裂之夜後，大陸上的三股人間勢力（2026-11-06 定案，細節留白）：

- **破曉軍團**：由各地冒險者、傭兵、滅亡國度的士兵聯合組成，在世界各地建立據點，保護平民。
- **鴉衛**：少數精銳組成的情報組織，目的是調查世界異象。人員很少，但都是菁英等級的高手，會在世界各地出沒。
- **天星商會**：龐大的金融帝國，異象發生前就幾乎壟斷整個世界的經濟；異象後仍能在各地販賣物資，有神秘管道保持貨物流通。藏身處的商人、之後的市集都屬於它。

## 7. 地理：照《山海經》（2026-11-09 定案，只寫方向，程式還沒接）

大陸的地理用《山海經》的結構當骨架：「五藏山經（南、西、北、東、中）→ 海外 → 海內 → 大荒」，剛好對上世界地圖從中心一圈一圈往外的樣子（`js/world.js` 的圈數 `wRing`）。

| 世界地圖 | 《山海經》 | 是什麼 |
| --- | --- | --- |
| 中心、劇情區（第 0～3 圈，地層出口到第 4 圈的環） | **中山** | 十二神鎮守的大陸中心。地層、藏身處在這裡；冥門就在中山底下 |
| 中圈（第 4 圈起） | **南、西、北、東四山** | 照方向分四種地貌，對應現有四種地圖場景（`js/biome.js`）：南山＝岩漿地城（火，祝融在南方）、北山＝冰雪洞窟（寒，北海神禺彊）、西山＝毒沼古墓、東山＝廢棄廟宇（⚠️ 西、東的對應暫定） |
| 外圈（越外越荒，Lv83 附近） | **海外、海內** | 異國與異人（奇肱國、三身國這類），人間勢力的手伸不到 |
| 最外圈 | **大荒** | 最荒蠻、最古老的地方；四凶的凶地在這裡，燭龍也在大荒（《大荒北經》） |

- 現在的區域名（`WREGION`：枯河原野、灰燼平原、血霧荒原、裂口腹地）只看圈數、不看方向，之後接地理時再決定要不要改名或加上方位（例：「南山・灰燼平原」）。
- 十二道裂口散在第 8～25 圈（四山之間），是十二神砸出來的。
- **怪物的方向**：之後的新怪物可以從《山海經》的異獸裡挑（九尾狐、畢方、猙、蠱雕等），出在牠原本所屬的那一經的方位；清單等做新怪物時再列。
