# 遊戲方向討論：找回刷寶的爽感（2026-11-11，討論中）

線上版（可以直接填「決定」欄、留言）：https://claude.ai/artifact/G9KJcHuzZyHtPgjctU76nM 。定案後把結果寫進 `企劃書.md` 2.1、4、5.4 節，這份再封存。

## 問題：戰鬥爽，刷寶不爽

掉寶那一刻被拿掉了。爽感來自「看到好東西掉下來 → 確認它是好的 → 變強」三步連在一起，0.3.x 把三步拆到不同時間、不同畫面。下面四點是讀企劃書 2.1、5.4 和 `game.js` 的 `pickup` 看出來的，還沒有數據。

| 原因 | 現在的做法 | 結果 |
| --- | --- | --- |
| 掉落當下看不到東西 | 0.3.3 起掉落全部吸過來，而且一律未鑑定 | ★ 光柱、標籤、落地音一出現就被吸走，只剩巡邏卡「撿到 N 件」 |
| 開獎離殺怪太遠 | 回家只有一行「N 件放進倉庫」，要走去撿骨師才翻牌 | 期待和揭曉中間隔了好幾張圖，期待冷掉 |
| 掉寶跟變強沒接上 | 未鑑定不能裝、AI 不換裝、▲▼ 要自己開說明框 | 刷到的寶不會讓戰鬥變爽 |
| 大獎太稀，沒有中間層 | ★ 每小時 2～3 件、追憶約 1 件，其他掉落看起來都一樣 | 十幾二十分鐘才一次有感事件 |

## 建議的方向：掉 → 亮 → 換 → 變強 → 升世界

固定地圖、守望石、背包接倉庫解決的是「刷得亂、刷到的用不上」；再加上掉落當下的訊號，四個機制接成一個循環：

```
掉落 → 亮 → 【換上】 → 變強 → 升世界
 ↑                                 │
 └──── 物品等級與 ★ 機率上去，掉得更好 ┘
```

「換上」是現在最缺的一段：掉寶接不到變強，已經很爽的戰鬥就帶不動刷寶。

| 機制 | 做法 | 給的樂趣 | 取代什麼 |
| --- | --- | --- | --- |
| 固定世界地圖 | 節點數固定；先照劇情開通，全打過後同時亮幾個、打完一個換一個 | 「下一個亮哪個」的小期待，選擇少不累 | 無限六角格、往外一圈 +3 級、區塊巡邏 |
| 守望石 | 插一顆全世界升一階：怪物等級、物品等級、T1 與 ★ 機率上去；守望石本身是大獎 | 推進的多巴胺，插上去整張地圖變色 | 「往外走」當進度 |
| 掉落當下的訊號 | ★、追憶、高品質、比身上好的吸走前停 0.5～1 秒：光柱、專屬音、畫面跳一行；普通的安靜吸走 | 殺王那一刻就開獎 | 全部立刻吸走＋未鑑定 |
| 背包接倉庫，一鍵換上 | 撿到的直接進大倉庫；比身上好的標 ▲、一鍵換上 | 換上那一刻戰鬥數字變大 | 背包 12×5＋兩頁臨時＋回家倒進倉庫 |

## 待決定：第一輪六個問題

六題彼此獨立，可以一次回答。

| # | 問題 | 選項 | 推薦 | 理由 | 決定 |
| --- | --- | --- | --- | --- | --- |
| Q1 | 固定地圖有幾個節點（劇情區 9 個之外） | (a) 5 地貌 × 4＝約 20 個＋機制節點　(b) 約 12 個，每個有特色　(c) 40 個以上 | (a) | 夠輪替，又能每個有名字、記得住「最愛刷哪張」 | |
| Q2 | 全部打過後怎麼輪流出現 | (a) 同時亮 3～5 個，打完一個隨機補一個　(b) 全部可打、只換卡　(c) 打完冷卻 N 張圖 | (a) 同時亮 4 個 | 「下一個亮哪個」是小期待；AI 巡邏改成在亮著的節點間挑 | |
| Q3 | 守望石怎麼拿、有幾階 | (a) 王有機率掉，偽隨機保底　(b) 一個殿或王場給一顆，約 8～10 顆　(c) 兩種都有 | (b) | 推進目標清楚，殿與王場有必打的理由；缺點是刷圖時不會突然掉 | |
| Q4 | 背包和倉庫合併到什麼程度 | (a) 完全合併成一個大倉庫，哪裡都能換裝　(b) 留背包，地圖裡可開倉庫　(c) 不合併，只做一鍵換上 | (a) | 掛機不需要「背包滿了回家清」的摩擦 | |
| Q5 | 未鑑定要不要留 | (a) 拿掉，掉落就看得到詞　(b) 留，王死時當場翻牌　(c) 留，回家自動彈開獎 | (a) | 掛機的開獎要在掉落當下；撿骨師的翻牌改用在王的 3 件掉落 | |
| Q6 | AI 要不要自動換裝 | (a) 戰力 +5% 以上自動換　(b) 只亮 ▲ 與「換上」鈕　(c) 設定讓玩家選 | (b) | 「看到 ▲、按下換上」是玩家自己的多巴胺；後期換不完再加 (a) | |

## 之後幾輪要問的

這些要等第一輪定了才能問，括號是它掛在哪一題上。

- 區塊卡、洗卡與 1～5★ 星級要不要留，還是改成每個亮著的節點直接帶一組詞（Q1、Q2）
- 十二道裂口、血霧、五條主線的殿與王場放在固定地圖的哪裡（Q1、Q3）
- 守望石每階漲多少：怪物等級、物品等級、T1 與 ★ 機率；要不要能拔掉降階（Q3）
- 倉庫滿了怎麼辦：停機、自動賣最爛的、還是自動拆成通貨（Q4）
- 中間層的掉落訊號分幾級、誰進哪一級：T1 詞、品質 20% 以上、好基底、少見通貨、比身上好（Q5）
- 「比身上好」怎麼算：用機器人的戰力分數，還是只比部位的主要數值（Q6）
- 舊存檔怎麼處理：照 0.3.0 的做法直接開新角色，還是轉換

## 還沒查證的與風險

- 還沒量現在每張圖的有感事件數；動手前先用 `stats` 量一次當基準，改完再比。另外要量「回家後多久打開倉庫」。
