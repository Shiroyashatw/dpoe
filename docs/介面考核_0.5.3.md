# 介面考核 0.5.3：營地、地點清單、掛機卡、王倒下、離線卡

2026-11-15，照 skill `ui-design` 當最挑剔的玩家看 0.5.3（12-B 做完）的畫面，手機直立 390×844 與桌機 1440×900 各截一輪（新存檔、模擬 20 分鐘後）。使用者的總評：「**增量介面完全做的很敷衍，完全沒有讓人有成長的感覺**」「為什麼要一直強調沒打過，解鎖打開玩家就自然會去打」「資源最爽不就是資源一直跑、進度條一直跳、資源還有 icon；本來資源條跑很慢，隨著升級會越來越快」。

打磨工項在 `archive/工項-0.2.63-0.5.4.md` 12-C（0.5.4，2026-11-15 做完：每條後面寫 ✓ 與怎麼修的）。✗＝不合格；每條寫是哪個維度（視覺／功能／操作）與病根。

## 病根（先修這三個，不逐條修）

1. **營地是一張清單，不是一座會動的營地。** 十張卡全部是「字＋字＋條＋鈕」，沒有圖示、沒有在跑的東西；資源只有一行小字 `木 21 +6/分`，一分鐘跳一次。三款增量遊戲的核心畫面是**每個產生器一條一直在跑的條、滿了數字跳一下、升級後跑更快**（`增量遊戲精髓.md` 5.3）。我們有速率、有 `g.acc`，但畫面上看不到它在動。
2. **文案一直講「不能」與「沒有」**：地點清單 21 列「瞭望台 Lv n 才開」、「還沒打」「打過」、卡片右上「還有 10 級」「還有 20 級」、掛機卡六格裡五格是 0、王倒下卡每次都教「要去更難的地方先升瞭望台」。玩家看到的是一面牆，不是一條往上的路。
3. **沒有「變強那一下」的演出**：升級只亮一下＋浮一個「+N／分」；主數字不滾、條不變快、沒有東西多出來（居民、工具、圖）。里程碑才有金邊與音效。
