# dungeonPOE

PoE 式增量遊戲：你配一套 build 讓角色自己去打，營地替你產材料；你打造裝備、升設施，設施帶你去更難的地方、解鎖更深的做裝。

- 線上遊玩：https://shiroyashatw.github.io/dpoe/ （以手機直立為主，桌機與手機橫向也能玩；可以加到主畫面當 App 用）
- 目前版本：v0.5.4（[更新紀錄](CHANGELOG.md)）

## 怎麼玩
1. 角色會自動刷目前的地點：王倒下就在同一個地點再刷一輪。
2. 到「營地」升產生器與設施：升瞭望台開下一個地點。
3. 在鍛造台打造、比較，然後換上或分解。

## 手機操作
底部五個分頁：戰利品、角色、技能、營地、更多。預設是自動（AI 操作角色），可以在「更多 → 設定」切成手動。

## 桌機快捷鍵
| 鍵 | 功能 |
| --- | --- |
| C | 自動／手動 |
| WASD | 移動（手動） |
| 滑鼠 | 瞄準（手動） |
| 左鍵 右鍵 Q E R | 技能（手動） |
| 空白 | 翻滾（怪物出手的瞬間翻滾＝完美閃避） |
| 1 ／ 2 | 生命藥劑 ／ 魔力藥劑 |
| F | 互動、撿東西 |
| V | 角色 |
| I ／ B | 倉庫 |
| G | 技能 |
| P | 天賦樹 |
| M | 地點 |
| K | 鍛造 |
| O | 鍛造 › 通貨 |
| H | 營地 |
| Z | 更多 |
| Tab | 下一個分頁（Shift＋Tab 上一個） |
| Y | 追逐物品（開放後） |
| U | 昇華石碑 |
| J | 山海寶盒 |
| L | 掉落紀錄 |
| T | 回營地（地圖裡先確認，再按一次 T＝回去） |
| Esc | 取消確認、關閉面板；都沒有時打開設定 |

## 本機執行與檢查
```bash
python3 -m http.server 8000      # 在 repo 根目錄，開 http://localhost:8000
node tools/check.js              # 固定檢查
node tools/touch_check.js 390 844  # 手機直立操作測試（要先開上面的伺服器）
```
