## 量測腳本強度
- 圖示：量的是 `getBoundingClientRect().width ÷ naturalWidth`，要 ≥1 而且是整數。弱點：清單是空的也會過（直立戰鬥 `#bar` 就量到 0 個；營地那條沒檢查數量）。上面的獨立量測補了數量。
- 地磚：換成標記地磚，掃描畫布，相鄰地磚寬差、相鄰材質像素寬差都要 ≤1。另外攔截 `drawImage` 檢查區塊是否落在整數畫布 px 上。是真的在量。不過遇到混色像素（`?`）時那一段直接丟掉不算失敗，這部分要靠對齊檢查兜住。
- 熱區：可點高度＝按鈕和每一層會裁切的父層、視窗取交集，再用 `elementFromPoint` 扣掉被黏住標題蓋到的部分。直立要 ≥44、桌機要 ≥32，而且至少 20 顆。是真的在量。
