## 擺放規則（實際用的）
- **每圈的 d**：「那一圈」＝同種類的 6 個孔（前期／交會／外圈大孔）。取這 6 個掛點跟**它直接相連的每個點**（E 裡的線）的直線距離，全部放在一起取中位數（偶數個取中間兩個平均）。**執行解讀**：交辦的「掛點到下一個點」解讀成「掛點到相連的點」。
  - 前期 d＝306.77（34 條線，86.0～521.6）→ 184.1～460.2
  - 交會 d＝97.44（28 條線，85.9～386.2）→ 58.5～146.2
  - 外圈大孔 d＝282.81（31 條線，85.9～407.1）→ 169.7～424.2
- **角度**：掛點的半徑方向（樹中心原點）偏 0、+5、−5、+10、−10 … ±45（19 個）；同角度差**先 + 後 −**，＋＝樹的角度（`atan2(x, −y)`）增加的方向＝畫面上順時針。
- **距離**：0.6d 起每 0.1d 到 1.5d（10 個）— **執行假設**（交辦沒指定）。
- **組合順序**：角度在外圈、距離在內圈（先把 0° 的 10 個距離試完，再試 +5°…）— **執行假設**。座標取到 0.1 後再檢查。
- **照 csv 順序一個一個放**，先放好的孔與它的線算進後面的檢查。
- **檢查**（跟 `pt2Audit` 同一套，孔當最小的點、半徑 10）：不超出 `pt2Rim`；孔跟每個點 ≥ max(最小點距 40.644, 半徑和＋8)、跟其他孔 ≥ 40.644；孔到每條線 ≥ 16；掛點→孔的線離每個點 ≥ 該點半徑＋6（含其他孔）；這條線不跟任何線交叉（含其他孔的線，共用端點的不算）；掛點上的線夾角 ≥ 0.21 rad。放完後再把孔與線加進 T，**整棵用 `pt2Audit` 重驗**：線交叉 0、線壓到點 0、兩點太近 0、夾角小於12度 0、全部連得到。
- **換掛點條件**（規則 2，analyze.js 原條件，不看分數）：幹道能力值點、不是其他孔的掛點、六起點到孔最少 ≥ 10 點；前期：同一條路（`round(角度/60)`）、自己起點到孔 10～15 點、半徑 ≤ 2300；交會：離交界（g×60+30）角度 ≤ JA、半徑 1700～JR（JA／JR 用 csv「挑選放寬」欄）、離其他孔的掛點 ≥ 4 步；外圈：同一條路、半徑 ≥ 3000、離其他孔的掛點 ≥ 4 步。離原掛點近的先試。
